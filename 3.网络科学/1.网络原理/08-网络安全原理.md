# 网络安全原理

> 解决什么问题：路由器/CPE 的安全边界在哪里，常见攻击面与防护手段是什么。
> 不解决：具体配置（→ [Netfilter 与防火墙](../../8.%E6%95%B0%E6%8D%AE%E9%9D%A2%E5%B7%A5%E7%A8%8B/02-Netfilter%E4%B8%8E%E9%98%B2%E7%81%AB%E5%A2%99.md)）、证书体系（→ [PKI 与证书](../../9.%E7%AE%A1%E7%90%86%E4%B8%8E%E5%AE%89%E5%85%A8/3.%E5%AE%89%E5%85%A8%E4%B8%8E%E8%AE%A4%E8%AF%81/01-PKI%E4%B8%8E%E8%AF%81%E4%B9%A6.md)）。

## 1. 威胁模型

| 资产 | 威胁 | 后果 |
|---|---|---|
| 管理面（Web/SSH/TR-069） | 弱口令、默认口令、未授权访问 | 设备被控、被植入 |
| 固件 | 未签名、降级、供应链篡改 | 持久化后门 |
| 配置/密钥 | 明文存储、日志泄露 | 凭证外泄 |
| WAN 暴露面 | 开放端口、UPnP 滥用、IPv6 默认暴露 | 被扫描/攻击 |
| 无线 | 弱加密、WPS、暴力破解 | 蹭网/中间人 |
| 调试接口 | 串口/ADB/JTAG 未关闭 | 物理接管 |
| 蜂窝 | SIM 克隆、IMEI 篡改 | 违规/封号 |

## 2. 密码学基础（够用即可）

| 能力 | 算法 | 用途 |
|---|---|---|
| 对称加密 | AES-GCM / ChaCha20-Poly1305 | 数据机密性 + 完整性 |
| 哈希 | SHA-256/384/512 | 完整性、口令派生 |
| 口令派生 | PBKDF2 / scrypt / Argon2 | 存储口令 |
| 非对称 | RSA / ECDSA / Ed25519 | 签名、密钥交换 |
| 密钥交换 | ECDHE | 前向保密 |
| 证书 | X.509 | 身份绑定 |

> 不要自创密码协议；用 TLS/IPsec/WireGuard 等成熟方案。

## 3. 认证与授权

| 概念 | 说明 | CPE 场景 |
|---|---|---|
| Authentication | 证明身份 | 管理员登录、ACS 认证、802.1X |
| Authorization | 能做什么 | 分级管理员、只读账号 |
| Accounting | 记录做了什么 | 操作日志、审计 |
| AAA | 三者合称 | 企业/运营商 |

常见错误：只做认证不做授权（普通用户能改 WAN）、日志记录明文口令、会话不过期。

## 4. 传输安全

| 方案 | 层 | 适用 |
|---|---|---|
| TLS | 应用层 | HTTPS、TR-069、Web 管理 |
| IPsec | 网络层 | 站点到站点、远程接入 |
| WireGuard | 网络层（UDP） | 轻量 VPN |
| 802.1X/EAP | 链路层 | 接入认证 |
| WPA2/WPA3 | 链路层（无线） | Wi-Fi |

TLS 要点：证书校验（不要 `verify=False`）、SNI、最低版本（TLS 1.2+）、强套件、证书轮换。

## 5. CPE 的默认安全基线

- [ ] 无默认/通用口令；首次登录强制修改。
- [ ] WAN 侧默认关闭 Web/SSH/Telnet；确需开放时限制源。
- [ ] 关闭 WPS、UPnP（或按需 + 白名单）。
- [ ] 固件签名校验；禁止降级到已知漏洞版本。
- [ ] 调试串口/ADB 量产关闭；保留受控恢复方式。
- [ ] 日志脱敏（口令、密钥、SIM 信息）。
- [ ] 最小服务集；不用的服务不安装。
- [ ] 时间同步（证书校验依赖正确时间）。
- [ ] 安全启动 + 只读根文件系统（可行时）。
- [ ] 漏洞响应流程（CVE 跟踪、补丁、通告）。

## 6. 常见攻击与防护

| 攻击 | 说明 | 防护 |
|---|---|---|
| 暴力破解 | 撞库/默认口令 | 强口令、锁定、验证码 |
| CSRF | 借用管理员会话 | Token、SameSite、来源校验 |
| XSS | Web 注入 | 输出编码、CSP |
| 命令注入 | 参数拼接进 shell | 白名单、避免 `system()` |
| 路径穿越 | 文件读取 | 规范化、根目录限制 |
| UPnP 滥用 | 私自开端口 | 关闭/白名单/日志 |
| DNS 劫持 | 篡改 DNS | DNSSEC/DoH/可信上游 |
| 中间人 | 证书伪造 | 证书校验、HSTS |
| 固件降级 | 刷旧版 | 防回滚计数器 |
| 物理接入 | 串口/JTAG | 关闭/加密/防拆 |

## 7. 与合规的关系

- CE/FCC 主要看无线与电磁兼容，不直接等于安全认证。
- 运营商入库通常有安全测试项（默认口令、开放端口、固件签名、日志）。
- 若产品出海，需关注 GDPR/CCPA 等数据合规。
