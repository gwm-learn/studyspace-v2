# Yocto 总览

> 解决什么问题：Yocto 的层次/配方/构建流程，能改镜像、加包、做 SDK，并能定位构建失败。
> 不解决：每个 recipe 的细节（见各章节与上游文档）。

## 1. 三个名字

| 名字 | 是什么 |
|---|---|
| Yocto Project | 项目/工具集/文档的集合 |
| OpenEmbedded | 元数据/配方生态（OE-Core） |
| BitBake | 构建引擎（类似 make，但处理配方/任务/依赖） |

## 2. 层次模型

```text
poky/
├── meta/                 # OE-Core 核心
├── meta-poky/            # Poky 发行版配置
├── meta-yocto-bsp/       # 参考板
└── meta-openembedded/    # 额外配方（需自行 clone）
```

项目层：

```text
meta-mycompany/
├── conf/
│   ├── layer.conf
│   ├── machine/*.conf
│   └── distro/*.conf
├── recipes-*/
└── recipes-kernel/
```

`bblayers.conf` 决定层顺序；层优先级影响覆盖关系。

## 3. 配置

| 文件 | 作用 |
|---|---|
| `conf/local.conf` | 机器/发行版/镜像特性/并行度 |
| `conf/bblayers.conf` | 启用哪些层 |
| `meta-*/conf/layer.conf` | 层元数据/优先级 |
| `machine.conf` | SoC/板级（内核/DTS/特性） |
| `distro.conf` | 发行版策略（init/systemd/包格式） |

常用：

```conf
MACHINE = "qemuarm64"
DISTRO = "poky"
PACKAGE_CLASSES = "package_rpm"
IMAGE_INSTALL:append = " openssh"
PARALLEL_MAKE = "-j 8"
BB_NUMBER_THREADS = "8"
```

## 4. 配方（recipe）

```text
recipes-demo/demo/demo_1.0.bb
```

```bitbake
SUMMARY = "demo"
LICENSE = "MIT"
LIC_FILES_CHKSUM = "file://LICENSE;md5=..."

SRC_URI = "git://example.com/demo.git;protocol=https;branch=main"
SRCREV = "abcdef..."

S = "${WORKDIR}/git"

inherit autotools pkgconfig

do_install:append() {
    install -d ${D}${sysconfdir}
    install -m 0644 ${S}/demo.conf ${D}${SYSCONFDIR}/demo.conf
}
```

| 变量 | 作用 |
|---|---|
| `SRC_URI` | 源码/补丁 |
| `SRCREV` | 版本 |
| `S` | 源码目录 |
| `D` | 安装暂存 |
| `FILES:${PN}` | 打包文件 |
| `RDEPENDS:${PN}` | 运行时依赖 |

`.bbappend` 用于在不改原配方的情况下追加/覆盖。

## 5. 构建流程

```text
fetch → unpack → patch → configure → compile → install → package → image
```

常用命令：

```bash
source oe-init-build-env build
bitbake core-image-minimal
bitbake -c listtasks demo
bitbake -c compile -f demo
bitbake -c cleanall demo
bitbake-layers show-layers
bitbake-layers add-layer ../meta-mycompany
```

## 6. 镜像

| 镜像 | 内容 |
|---|---|
| `core-image-minimal` | 最小可启动 |
| `core-image-base` | 基础工具 |
| `core-image-full-cmdline` | 完整命令行 |
| `core-image-sato` | GUI |
| 自定义 | `IMAGE_INSTALL`/`IMAGE_FEATURES` |

## 7. SDK

```bash
bitbake meta-toolchain
bitbake core-image-minimal -c populate_sdk
```

生成安装包，包含交叉工具链/sysroot；用于应用开发。

## 8. 加速与缓存

- `SSTATE_DIR`/`SSTATE_MIRRORS`：共享状态缓存。
- `DL_DIR`：下载缓存。
- `ccache`：编译缓存。
- 本地磁盘/网络/内存要求较高。

## 9. 常见问题

| 现象 | 首查 |
|---|---|
| 找不到配方 | 层未加/优先级/命名 |
| 编译失败 | 依赖/补丁/工具链 |
| 许可证报错 | `LIC_FILES_CHKSUM` |
| 下载失败 | 网络/镜像/代理 |
| 磁盘满 | `TMPDIR`/清理 |
| 结果不可复现 | 版本/层/sstate |
| SDK 缺库 | `populate_sdk`/依赖 |

## 10. 与 Buildroot/OpenWrt 的取舍

- 多产品/长维护/强定制：Yocto。
- 固定功能/小体积：Buildroot。
- 路由器/网络设备：OpenWrt。
- 学习成本/构建资源：Yocto 最高。
