# 重要配置路径清单


| 路径 | 用途 |
|------|------|
| `include/image.mk` | 镜像构建核心框架（Device/Build/*, BuildImage, Image/mkfs/*, 1017 行） |
| `include/image-commands.mk` | 所有 Build/ 命令定义（append-kernel, fit, ubinize, fwtool... 877 行） |
| `include/kernel-build.mk` | 内核编译入口（BuildKernel, compile/install 目标，187 行） |
| `include/kernel.mk` | 内核变量定义（LINUX_VERSION, KERNEL_BUILD_DIR 等） |
| `target/linux/mediatek/Makefile` |mediatek 平台 Makefile（17 行） |
| `target/linux/mediatek/filogic/target.mk` | Filogic subtarget 定义（11 行） |
| `target/linux/mediatek/image/Makefile` |mediatek 镜像入口（48 行，include filogic.mk） |
| `target/linux/mediatek/image/filogic.mk` |MT7981 设备定义（3868 行，47+ 设备） |
| `scripts/mkits.sh` | FIT .its 文件生成器（244 行） |
| `scripts/ubinize-image.sh` | UBI 镜像合成脚本（170 行） |
| `scripts/sysupgrade-tar.sh` | sysupgrade tar 打包脚本（92 行） |
| `package/boot/arm-trusted-firmware-mediatek/Makefile` | BL2/BL31 源码构建（ATF，git 外源） |
| `package/boot/uboot-mediatek/Makefile` | U-Boot + FIP 构建（47 MT7981 变体，git 外源） |
| `package/system/fwtool/Makefile` | fwtool host 工具（签名/元数据，git 外源） |
| `package/utils/fitblk/Makefile` | fitblk 用户态工具 |
| `target/linux/mediatek/dts/mt7981b-openwrt-one.dts` |openwrt_one 完整设备树（含分区布局） |
| `target/linux/mediatek/filogic/base-files/lib/upgrade/platform.sh` | 升级路径判定（fit_do_upgrade / emmc_do_upgrade / nand_do_upgrade） |
