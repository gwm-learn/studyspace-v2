# 关键配置变量速查


| 变量 | filogic 默认值 | 说明 |
|------|--------------|------|
| `ARCH` | `aarch64` | ARM64 (Cortex-A53) |
| `KERNELNAME` | `Image dtbs` | 内核输出文件名 |
| `KERNEL_LOADADDR` | `0x48000000` | Filogic 默认内核加载地址 |
| `DEVICE_DTS_LOADADDR` | `0x43f00000` | DTB 加载地址 (openwrt_one 等) |
| `FILESYSTEMS` | `squashfs erofs` | 默认支持的文件系统 |
| `PAGESIZE` | `2048` | NAND 页大小（字节） |
| `BLOCKSIZE` | `128k` | NAND 物理擦除块大小 |
| `UBINIZE_OPTS` | `-E 5` | UBI 擦除对齐参数 |
| `SQUASHFS_BLOCK_SIZE` | `CONFIG_TARGET_SQUASHFS_BLOCK_SIZE`k | squashfs 块大小 |
| `SQUASHFSCOMP` | `gzip`（默认）/ `xz`（开启后） | 压缩算法 |
| `UBOOT_IMAGE` | `u-boot.fip` | U-Boot 输出格式 |

**Device/Default 中的镜像管线默认值** (`target/linux/mediatek/image/Makefile:20-33`)：
```
KERNEL := kernel-bin | lzma | fit lzma $(KDIR)/image-$(DTS).dtb
IMAGES := sysupgrade.bin
IMAGE/sysupgrade.bin := append-kernel | pad-to 128k | append-rootfs | pad-rootfs | append-metadata
```

**openwrt_one 的覆盖值**：
```
KERNEL := kernel-bin | gzip              # 不用 lzma，用 gzip
KERNEL_LOADADDR := 0x44000000           # 低于默认值
KERNEL_IN_UBI := 1
IMAGES := sysupgrade.itb                # 用 FIT 格式
IMAGE/sysupgrade.itb := append-kernel | fit gzip ... external-with-rootfs ...
```
