# 并发与锁调试（内核）

> 解决什么问题：内核死锁、睡眠在原子上下文、竞态、RCU 误用。
> 不解决：用户态并发（见 [并发与同步](../../2.计算机科学/4.并发与系统编程/01-并发与同步.md)）。

## 1. 上下文

| 上下文 | 能否睡眠 | 可用锁 |
|---|---|---|
| 进程 | 可 | mutex/spinlock/rwlock |
| 软中断 | 不可 | spinlock（irqsave 视情况） |
| 硬中断 | 不可 | spinlock_irqsave |
| NMI | 不可 | 特殊 |

**睡眠在原子上下文**是最常见错误。

## 2. 锁选择

| 场景 | 锁 |
|---|---|
| 进程上下文、可睡眠 | mutex |
| 中断/软中断共享 | spinlock + irqsave |
| 读多写少 | rwlock/seqlock/RCU |
| 计数/标志 | atomic |
| 等待条件 | waitqueue/completion |
| 时间戳/序列 | seqlock |

## 3. 规则

- 锁顺序全局一致；文档化。
- 临界区短；不调用可能睡眠的函数。
- 中断上下文用 `spin_lock_irqsave`。
- RCU 读侧不能睡眠；写侧延迟释放。
- 避免在持锁时拷贝大量用户数据/IO。

## 4. 调试配置

```text
CONFIG_PROVE_LOCKING=y
CONFIG_DEBUG_ATOMIC_SLEEP=y
CONFIG_DEBUG_SPINLOCK=y
CONFIG_DEBUG_MUTEXES=y
CONFIG_KASAN=y
CONFIG_KCSAN=y
CONFIG_RCU_TRACE=y
```

## 5. 常见报错

| 报错 | 含义 | 处理 |
|---|---|---|
| possible circular locking dependency | 锁顺序环 | 调整顺序/拆锁 |
| sleeping function called from invalid context | 原子上下文睡眠 | 改 GFP/移出临界区 |
| BUG: spinlock lockup | 死锁/中断关太久 | 查持有者/缩短临界区 |
| KASAN: use-after-free | 生命周期 | 查释放/RCU |
| KCSAN: data race | 数据竞争 | 加锁/atomic |
| RCU stall | 读侧阻塞 | 查长循环/睡眠 |

## 6. 死锁排查

```bash
# 内核栈
echo l > /proc/sysrq-trigger
dmesg | tail
# 或
cat /proc/<pid>/stack
```

- 找“谁持有锁、谁在等”。
- 看是否 AB/BA。
- 看是否在中断上下文等进程锁。

## 7. RCU

- `rcu_read_lock()`/`rcu_read_unlock()` 读侧。
- 写侧更新指针 + `synchronize_rcu()` 或 `call_rcu()` 释放。
- 读侧不能睡眠/阻塞。
- 适合路由表/配置等读多写少。

## 8. 检查表

- [ ] 锁与上下文匹配。
- [ ] 锁顺序一致。
- [ ] 临界区不睡眠。
- [ ] 中断用 irqsave。
- [ ] RCU 读侧不阻塞。
- [ ] 开 lockdep/KASAN 跑测试。
