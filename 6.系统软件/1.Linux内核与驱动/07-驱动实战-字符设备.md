# 驱动实战：字符设备

> 解决什么问题：从零写一个可加载、可读写、可 ioctl、可并发的字符设备，并知道怎么测。
> 不解决：具体硬件寄存器操作（按 datasheet）。

## 1. 设备号

| 概念 | 说明 |
|---|---|
| major | 主设备号，标识驱动 |
| minor | 次设备号，标识实例 |
| `dev_t` | major+minor |
| `alloc_chrdev_region` | 动态分配 |
| `register_chrdev_region` | 指定 |

查看：`cat /proc/devices`。

## 2. 骨架

```c
#include <linux/cdev.h>
#include <linux/fs.h>
#include <linux/uaccess.h>

static dev_t dev;
static struct cdev cdev;
static struct class *cls;

static int demo_open(struct inode *i, struct file *f) { return 0; }
static int demo_release(struct inode *i, struct file *f) { return 0; }

static ssize_t demo_read(struct file *f, char __user *buf,
                         size_t n, loff_t *off) {
    char kbuf[] = "hello\n";
    if (*off >= sizeof(kbuf)) return 0;
    if (n > sizeof(kbuf) - *off) n = sizeof(kbuf) - *off;
    if (copy_to_user(buf, kbuf + *off, n)) return -EFAULT;
    *off += n;
    return n;
}

static ssize_t demo_write(struct file *f, const char __user *buf,
                          size_t n, loff_t *off) {
    char kbuf[64];
    if (n > sizeof(kbuf)) return -EINVAL;
    if (copy_from_user(kbuf, buf, n)) return -EFAULT;
    pr_info("demo write %zu bytes\n", n);
    return n;
}

static long demo_ioctl(struct file *f, unsigned int cmd, unsigned long arg) {
    switch (cmd) {
    case 0: return 0;
    default: return -ENOTTY;
    }
}

static const struct file_operations fops = {
    .owner = THIS_MODULE,
    .open = demo_open,
    .release = demo_release,
    .read = demo_read,
    .write = demo_write,
    .unlocked_ioctl = demo_ioctl,
};

static int __init demo_init(void) {
    alloc_chrdev_region(&dev, 0, 1, "demo");
    cdev_init(&cdev, &fops);
    cdev_add(&cdev, dev, 1);
    cls = class_create(THIS_MODULE, "demo");
    device_create(cls, NULL, dev, NULL, "demo0");
    return 0;
}

static void __exit demo_exit(void) {
    device_destroy(cls, dev);
    class_destroy(cls);
    cdev_del(&cdev);
    unregister_chrdev_region(dev, 1);
}
module_init(demo_init);
module_exit(demo_exit);
MODULE_LICENSE("GPL");
```

## 3. 用户态测试

```bash
sudo insmod demo.ko
cat /dev/demo0
echo hi > /dev/demo0
sudo rmmod demo
dmesg | tail
```

## 4. 并发与生命周期

- 多个进程可同时 open/read/write；共享数据要加锁。
- `open` 可分配 per-file 私有数据：`f->private_data`。
- `release` 要释放。
- 卸载前确保没有打开的文件（否则 `rmmod` 失败/崩溃）。

## 5. ioctl 规范

```c
#define DEMO_IOC_MAGIC 'D'
#define DEMO_GET _IOR(DEMO_IOC_MAGIC, 1, int)
#define DEMO_SET _IOW(DEMO_IOC_MAGIC, 2, int)
```

- 用 `_IO/_IOR/_IOW/_IOWR` 定义，避免命令冲突。
- 校验参数/长度/权限。
- 不要直接解引用用户指针。

## 6. 常见坑

| 坑 | 说明 |
|---|---|
| `copy_to_user` 返回非 0 | 用户缓冲区无效 |
| 忘记 `cdev_del` | 卸载崩溃 |
| 设备节点权限 | udev/root |
| 并发 open/read | 需要锁/原子 |
| 直接解引用用户指针 | 必须 copy_*_user |
| 模块许可 | 非 GPL 可能限制符号 |
