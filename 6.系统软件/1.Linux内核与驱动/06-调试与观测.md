# 内核调试与观测

> 解决什么问题：内核崩溃、卡死、性能异常、网络丢包时，如何在不加 printk 的情况下拿到证据。
> 不解决：用户态调试（→ [调试工具链](../../10.%E5%B7%A5%E7%A8%8B%E6%96%B9%E6%B3%95/1.%E8%B0%83%E8%AF%95%E4%B8%8E%E6%80%A7%E8%83%BD/01-%E8%B0%83%E8%AF%95%E5%B7%A5%E5%85%B7%E9%93%BE.md)）。

## 1. 工具地图

| 场景 | 工具 | 入口 |
|---|---|---|
| 函数调用/延迟 | ftrace | `/sys/kernel/debug/tracing` |
| 性能采样 | perf | `perf top/record/report` |
| 动态日志 | dynamic_debug | `/sys/kernel/debug/dynamic_debug/control` |
| 崩溃转储 | pstore/ramoops | `/sys/fs/pstore` |
| 断点调试 | kgdb/JTAG | 串口/网口 + gdb |
| 网络丢包 | drop_monitor/tracepoint | `perf trace`/ftrace events |
| 内存 | kmemleak/slabinfo | debugfs |

## 2. ftrace

```bash
cd /sys/kernel/debug/tracing
echo function_graph > current_tracer
echo 'ip_rcv' > set_graph_function
echo 1 > tracing_on
# 触发流量
echo 0 > tracing_on
cat trace
```

常用：

```bash
# 事件
echo 1 > events/net/enable
# 过滤
echo 'ip_rcv' > set_ftrace_filter
# 函数耗时
echo function > current_tracer
```

## 3. perf

```bash
perf top
perf record -g -a -- sleep 10
perf report
perf stat -e cycles,instructions,cache-misses -a -- sleep 5
```

嵌入式注意：需要 `CONFIG_PERF_EVENTS`、符号表（vmlinux）、足够的 ring buffer。

## 4. 动态调试

```bash
# 打开某个文件的 debug 输出
echo 'file net/ipv4/arp.c +p' > /sys/kernel/debug/dynamic_debug/control
dmesg -w
```

## 5. 崩溃与 pstore

```bash
cat /sys/fs/pstore/*
```

需要 DTS 中保留 ramoops 内存区；否则重启后无日志。

## 6. kgdb

```bash
# 内核 cmdline
kgdboc=ttyS0,115200 kgdbwait

# 主机
gdb vmlinux
(gdb) target remote /dev/ttyUSB0
```

量产设备通常关闭；研发用 JTAG/串口。

## 7. 网络专项

| 问题 | 方法 |
|---|---|
| 丢包 | `perf trace -e skb:kfree_skb`、drop_monitor |
| 收包延迟 | ftrace `netif_receive_skb` |
| 软中断 | `mpstat -P ALL`、`/proc/softirqs` |
| conntrack | `conntrack -S`、`/proc/net/stat/nf_conntrack` |
| qdisc | `tc -s qdisc` |
