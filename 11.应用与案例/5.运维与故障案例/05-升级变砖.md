# 案例：升级变砖

> 说明：定位框架 + 恢复路径；具体分区/命令按板子。

## 1. 现象

- 升级后无法启动；串口停在 U-Boot/内核；反复重启。
- 管理页面打不开；WAN/LAN 无响应。
- 部分设备可进恢复模式，部分完全无输出。

## 2. 启动链定位

```text
BootROM → BL2/FIP → U-Boot → kernel/DTB → rootfs → procd
```

| 停在哪 | 可能原因 |
|---|---|
| 无任何输出 | 供电/串口/BootROM |
| BL2 后 | DDR/启动介质 |
| U-Boot | 环境变量/镜像/分区 |
| 内核 | bootargs/DTB/rootfs |
| rootfs | 挂载/overlay |
| 用户态 | 服务/配置 |

## 3. 证据

```text
串口完整启动日志
U-Boot printenv
分区表/mtdparts
镜像 board/version
升级前后版本
```

## 4. 常见根因

| 根因 | 说明 |
|---|---|
| 镜像不匹配 | 刷错型号/分区布局 |
| 分区错 | kernel/rootfs 偏移/大小 |
| bootargs 错 | console/root/mtdparts |
| DTB 错 | 板级不匹配 |
| rootfs 损坏 | 下载/写入/校验 |
| overlay 满 | 升级后配置写不下 |
| A/B 标志错 | 启动槽/回滚 |
| 断电 | 写入中断 |

## 5. 恢复路径

1. **U-Boot 可用**：TFTP/USB 重新加载镜像。
2. **BootROM 可用**：进入下载模式（USB/串口）。
3. **JTAG/离线烧录**：最后手段。
4. **A/B**：切回旧槽。

> 具体按键/工具按板子；不要凭记忆操作。

## 6. 修复

| 场景 | 动作 |
|---|---|
| 镜像错 | 刷正确型号 |
| 分区错 | 恢复分区表/uboot-env |
| rootfs 坏 | 重刷/校验 |
| 配置坏 | 清 overlay/恢复出厂 |
| A/B 失败 | 切槽/修标志 |

## 7. 预防

- 镜像校验 board/version/签名。
- A/B + 启动计数回滚。
- 升级前备份 factory/uboot-env。
- 灰度发布/分批。
- 断电保护/断点续传。
- 升级后自检/失败回滚。

## 8. 复盘问题

1. 停在哪一段？
2. 是镜像、分区、配置还是断电？
3. 为什么没有回滚？
4. 下次如何提前阻断？
