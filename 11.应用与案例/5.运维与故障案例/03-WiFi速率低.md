# 案例：WiFi 速率低

> 说明：定位框架 + 常见根因；具体数值按现场/终端替换。

## 1. 先分层

```text
终端 → 空口 → AP（hostapd/mac80211/驱动）→ 网桥/VLAN → 路由/NAT → 上游
```

每一层都可能“看起来是 WiFi 慢”。

## 2. 必看指标

```bash
iw dev wlan0 link
iw dev wlan0 station dump
iw dev wlan0 survey
ip -s link show wlan0
cat /proc/net/wireless
```

| 指标 | 异常含义 |
|---|---|
| RSSI/SNR | 覆盖/干扰 |
| 协商速率 | 频宽/空间流/MCS |
| 重传/失败 | 干扰/弱信号 |
| 信道 busy | 拥塞 |
| 终端能力 | 只支持 2.4G/单流 |

## 3. 分层证据

| 层 | 证据 |
|---|---|
| 终端 | 支持的频段/协议/空间流 |
| 空口 | 信道/干扰/重传/速率 |
| AP | hostapd 日志/驱动日志 |
| 二层 | 网桥/VLAN/隔离 |
| 三层 | 路由/NAT/conntrack |
| 上游 | 有线基线/宽带 |

## 4. 常见根因

### 4.1 覆盖/干扰

- 距离远/遮挡/金属。
- 2.4G 拥挤（微波/蓝牙/邻区）。
- 5G 信道/DFS/雷达。
- 终端天线差。

### 4.2 配置

- 频宽 20 MHz/40 MHz 选择。
- 空间流/天线数量。
- 加密/PMF/漫游。
- 省电模式。

### 4.3 回程/有线

- 有线口百兆/协商失败。
- 网桥/VLAN/CPU 瓶颈。
- 上游宽带/运营商限速。

### 4.4 终端

- 只支持 2.4G/单流。
- 驱动/省电/漫游策略。
- 后台更新/多应用。

## 5. 定位步骤

1. 测有线基线（排除上游）。
2. 近点测 WiFi（排除覆盖）。
3. 换终端/换信道（排除终端/干扰）。
4. 看 `station dump` 速率/重传。
5. 抓空口/网桥包（看重传/丢包）。
6. 对比开/关功能（QoS/加速/漫游）。

## 6. 修复

| 根因 | 动作 |
|---|---|
| 覆盖 | 加 AP/调位置/天线 |
| 干扰 | 换信道/降频宽/屏蔽 |
| 终端 | 换 5G/双流终端 |
| 有线 | 换线/查协商 |
| 配置 | 调频宽/功率/漫游 |
| 上游 | 运营商/宽带 |

## 7. 预防

- 记录终端能力/信道/速率基线。
- 现场勘测/热力图。
- 监控重传/信道利用率。
- 高密度按容量规划，不盲目加功率。

## 8. 复盘问题

1. 瓶颈在空口/有线/上游？
2. 证据是什么？
3. 是覆盖、干扰还是终端？
4. 下次如何提前发现？
