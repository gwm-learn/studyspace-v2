# 案例：5G/LTE 掉线

> 说明：定位框架 + 常见根因；具体模组/运营商需替换。

## 1. 分层

```text
SIM/UIM → 射频/小区 → 注册/信令 → 数据会话 → 网络接口 → 路由/NAT → 业务
```

掉线可能发生在任何一层。

## 2. 证据

```bash
logread | grep -i -E 'qmi|mbim|ppp|wwan|modem'
qmicli -d /dev/cdc-wdm0 --nas-get-signal-info
qmicli -d /dev/cdc-wdm0 --nas-get-serving-system
ip -s link show wwan0
dmesg | grep -i -E 'usb|qmi|option'
```

| 层 | 指标 |
|---|---|
| 射频 | RSRP/RSRQ/SINR、频段/PCI |
| 注册 | 注册状态/去注册原因 |
| 数据 | PDN/会话/IP |
| 接口 | wwan0 收发包/错误 |
| 供电 | 峰值电流/压降 |
| 温度 | 模组/整机 |

## 3. 常见根因

### 3.1 射频/覆盖

- 弱信号/边缘/遮挡。
- 频段/小区选择/飘站。
- 干扰/负载。

### 3.2 供电/热

- 发射峰值电流导致压降/复位。
- USB 供电不足/线损。
- 高温降频/保护。

### 3.3 模组/固件

- 固件 bug/兼容性。
- USB 枚举不稳定。
- QMI/MBIM 会话异常。

### 3.4 配置

- APN/IPv4v6/鉴权。
- 路由/NAT。
- 重拨/保活缺失。

## 4. 定位步骤

1. 看信号/注册状态。
2. 看数据会话/IP。
3. 看 wwan0 统计/错误。
4. 看供电/温度。
5. 看模组日志/固件版本。
6. 换卡/换位置/换模组对比。

## 5. 修复

| 根因 | 动作 |
|---|---|
| 弱信号 | 天线/位置/锁频 |
| 供电 | 加电容/改线/限流 |
| 高温 | 散热/降频 |
| 固件 | 升级/回退验证 |
| 配置 | APN/路由/重拨 |
| 飘站 | 锁频/锁小区（谨慎） |

## 6. 预防

- 重拨/探活/看门狗。
- 记录掉线原因/信号/温度。
- 现场信号勘测。
- 模组固件版本管理。

## 7. 复盘问题

1. 掉线是射频、信令、数据还是供电？
2. 证据是什么？
3. 是否可远程恢复？
4. 下次如何提前发现？
