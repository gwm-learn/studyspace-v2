# 认证与运营商入库

> 解决什么问题：产品从"能卖"到"能合法卖、能进运营商"需要哪些认证与测试。
> 不解决：具体实验室报价与排期。

## 1. 认证地图

| 认证 | 地区 | 关注 | 典型标准 |
|---|---|---|---|
| CE / RED | 欧盟 | 无线、EMC、安全、健康 | RED 2014/53/EU, EN 300 328/301 893, EN 55032/55035 |
| FCC | 美国 | 无线、EMC | Part 15C/E, Part 15B |
| 3C | 中国 | 安全、EMC（部分产品） | GB 4943.1, GB/T 9254 |
| SRRC | 中国 | 无线电型号核准 | 工信部相关 |
| 运营商入库 | 运营商 | 协议、性能、安全、运维 | 企业规范 |

> 具体适用标准随产品形态（Wi-Fi/蜂窝/PoE）变化，必须由认证机构确认。

## 2. 常见测试项

| 类别 | 项目 |
|---|---|
| 射频 | 频率/功率/带宽/杂散/占用时间/DFS |
| EMC | 辐射/传导发射、抗扰度、ESD、浪涌 |
| 安全 | 绝缘、温升、防火、电池（如有） |
| 健康 | SAR/MPE（靠近人体的设备） |
| 协议 | PPPoE/DHCP/IPv6/TR-069/Wi-Fi 互通 |
| 性能 | 吞吐、时延、并发、稳定性 |
| 安全 | 默认口令、开放端口、固件签名、日志 |
| 运维 | ACS 对接、升级、恢复、诊断 |

## 3. 运营商入库流程（典型）

```text
需求对齐 → 样机送测 → 预测试 → 问题整改 → 正式测试 → 报告评审 → 入库
```

| 阶段 | 产出 |
|---|---|
| 需求对齐 | 测试规范、版本基线、接口人 |
| 样机送测 | 硬件/固件/配件/文档 |
| 预测试 | 问题清单、整改计划 |
| 正式测试 | 测试报告、遗留问题 |
| 评审 | 入库结论、版本冻结 |

## 4. 文档清单

- [ ] 产品规格书、用户手册、快速安装指南。
- [ ] 原理图、BOM、PCB 叠层（按需）。
- [ ] 射频参数、天线报告、EIRP 计算。
- [ ] 软件版本、开源许可证清单（SBOM）。
- [ ] 安全说明（默认口令、端口、升级机制）。
- [ ] 标签/铭牌（型号、电源、认证标识）。
- [ ] 测试报告与整改记录。

## 5. 常见坑

| 坑 | 后果 | 对策 |
|---|---|---|
| 认证版本与量产版本不一致 | 报告失效 | 冻结版本，变更重新评估 |
| 天线/外壳变更未报备 | 射频指标超限 | 变更管理 |
| 默认口令/开放端口 | 安全测试失败 | 出厂加固 |
| IPv6/TR-069 未测 | 入库阻塞 | 提前联调 |
| 只测实验室环境 | 现场不达标 | 外场/弱网测试 |
| 标签/说明书错误 | 返工 | 法务/认证预审 |

## 6. 时间与成本（经验）

- CE/FCC：通常 4–8 周（含整改）。
- SRRC：通常 8–12 周。
- 运营商入库：1–3 个月，取决于整改轮次。
- 预留至少 1 轮整改缓冲。
