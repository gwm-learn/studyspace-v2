# 产测与校准

> 解决什么问题：从"研发样机"到"批量一致"：每台设备怎么测、怎么校准、怎么追溯。
> 不解决：具体产线设备型号与治具设计。

## 1. 产线流程

```text
SMT/组装 → 单板测试 → 整机测试 → 校准 → 老化 → 终检 → 包装 → 入库
```

| 阶段 | 目标 | 典型项 |
|---|---|---|
| 单板测试 | 焊接/器件 | 电源、时钟、DDR、Flash、网口 |
| 整机测试 | 功能 | 启动、网口、Wi-Fi、USB、按键/LED |
| 校准 | 射频一致性 | 功率、频偏、EVM、灵敏度 |
| 老化 | 早期失效 | 高温满载 4–24 h |
| 终检 | 出厂一致性 | 外观、标签、配件、固件版本 |

## 2. 关键数据写入

| 数据 | 来源 | 写入位置 | 注意 |
|---|---|---|---|
| MAC | 厂商 OUI + 分配 | factory/EEPROM | 唯一、可追溯 |
| SN | MES | factory/EEPROM | 与包装/标签一致 |
| 型号/版本 | 生产工单 | factory | 防刷错固件 |
| Wi-Fi 校准 | 校准工位 | factory/art | 丢失导致功率/速率异常 |
| 私钥/证书 | PKI | 安全存储 | 不可导出、不可共用 |
| 区域码 | 销售区域 | factory/配置 | 影响信道/功率 |

## 3. 校准

| 项 | 说明 |
|---|---|
| 功率校准 | 每信道/每频段/每天线 |
| 频偏校准 | 晶振/参考时钟 |
| 增益/驻波 | 射频链路 |
| 灵敏度 | 接收链路 |
| 温度补偿 | 高低温下的功率漂移 |

要点：
- 校准环境（屏蔽箱/暗室）与仪器要定期校准。
- 校准数据必须与设备绑定，不能整批复制。
- 校准失败要有明确判定与返修流程。

## 4. 老化与可靠性

| 项 | 建议 |
|---|---|
| 温度 | 高温（如 55–70°C）满载 |
| 时间 | 4–24 h，按产品定位 |
| 监控 | 重启、掉线、温度、功耗 |
| 抽样 | 批量抽检 + 关键项目全检 |
| 记录 | 每台/每批数据入库 |

## 5. 追溯

- 一机一码：SN ↔ MAC ↔ 校准数据 ↔ 测试记录 ↔ 出货批次。
- MES/工单绑定；返修记录可查。
- 固件版本与认证版本一致；变更要走变更管理。

## 6. 常见问题

| 现象 | 原因 |
|---|---|
| 批量 MAC 冲突 | 分配表/写入脚本错误 |
| Wi-Fi 功率不达标 | 校准数据丢失/写错分区 |
| 部分机器反复重启 | 电源/焊接/器件批次 |
| 老化后失效 | 早期失效/散热/电容 |
| 出货版本错 | 工单/固件包管理混乱 |
| 认证与量产不一致 | 变更未评估 |

## 7. 最小检查表

- [ ] 每台有唯一 SN/MAC，且与包装一致。
- [ ] 校准数据已写入并回读校验。
- [ ] 固件版本/区域码正确。
- [ ] 关键射频指标在阈值内。
- [ ] 老化无重启/掉线。
- [ ] 测试记录可追溯。
- [ ] 不良品有隔离与返修流程。
