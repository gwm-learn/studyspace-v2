# 产线数据模板

> 用途：定义每台设备的可追溯数据与测试明细；字段按项目裁剪。
> 目标：一机一档，能回答“谁、何时、什么版本、测了什么、结果如何、返修过没有”。

## 1. 数据模型

```text
工单/批次
  └─ 设备（SN）
       ├─ 基础信息（型号/硬件版本/固件/校准版本）
       ├─ 测试记录（多项）
       ├─ 校准记录（多项）
       ├─ 老化记录
       └─ 返修/出货记录
```

## 2. 主表（每台一条）

| 字段 | 类型 | 示例 | 必填 | 说明 |
|---|---|---|---|---|
| record_id | string | 20261024-001 | ✅ | 唯一 |
| SN | string | SN123456 | ✅ | 唯一 |
| MAC | string | 00:11:22:33:44:55 | ✅ | 唯一 |
| 型号 | string | X1 | ✅ | 与认证一致 |
| 硬件版本 | string | REV-A | ✅ | BOM 变更 |
| 固件版本 | string | 1.2.3 | ✅ | commit |
| 校准版本 | string | cal-2026-10 | ✅ | 数据版本 |
| 工单/批次 | string | WO-1001 | ✅ | 追溯 |
| 工位 | string | FT-03 | ✅ | 设备/治具 |
| 操作员 | string | op01 | ✅ | 责任 |
| 开始/结束 | datetime | — | ✅ | 耗时 |
| 结果 | enum | PASS/FAIL | ✅ | — |
| 不良代码 | string | E-PWR-01 | 条件 | 分类 |
| 返修次数 | int | 0 | ✅ | — |

## 3. 测试明细（每台多条）

| 项 | 单位 | 下限 | 上限 | 实测 | 判定 | 工位 |
|---|---|---:|---:|---:|---|---|
| 输入电压 | V | 11.4 | 12.6 | | | |
| 待机电流 | mA | — | 300 | | | |
| 峰值电流 | A | — | 2.5 | | | |
| 网口1 | Mbps | 900 | — | | | |
| 网口2 | Mbps | 900 | — | | | |
| Wi-Fi 2.4G 功率 | dBm | 18 | 22 | | | |
| Wi-Fi 5G 功率 | dBm | 18 | 22 | | | |
| 频偏 | ppm | -20 | 20 | | | |
| EVM | % | — | 5 | | | |
| 灵敏度 | dBm | -95 | — | | | |
| 吞吐 | Mbps | 600 | — | | | |
| 按键/LED | — | PASS | PASS | | | |

> 阈值来自设计/校准/历史数据；变更要评审并记录版本。

## 4. 校准记录

| 字段 | 说明 |
|---|---|
| 校准项 | 功率/频偏/EVM/灵敏度 |
| 信道/频段 | 覆盖范围 |
| 原始值/补偿值 | 可回读 |
| 仪器/工位 | 追溯 |
| 校准时间 | — |
| 操作员 | — |

## 5. 老化记录

| 字段 | 说明 |
|---|---|
| 温度/时长 | 55–70 °C / 4–24 h |
| 负载 | 满载/周期业务 |
| 监控 | 重启/掉线/温度/电流 |
| 复测 | 关键指标 |
| 结果 | PASS/FAIL |

## 6. 数据质量

| 问题 | 对策 |
|---|---|
| 缺字段 | 必填校验 |
| 手工录入错 | 扫码/自动采集 |
| 阈值漂移 | 定期评审/版本 |
| 记录丢失 | 本地+服务器 |
| 版本不一致 | 工单绑定 |
| 重复 SN/MAC | 唯一约束 |

## 7. 安全与保留

- 客户/运营商数据脱敏。
- MAC/SN/密钥分级权限。
- 保留周期按合同/法规。
- 导出/共享需审批。
- 备份/恢复演练。

## 8. 追溯查询

```text
按 SN 查：基础信息 + 测试 + 校准 + 老化 + 返修 + 出货
按批次查：不良率 + 失败项分布 + 趋势
按不良代码查：根因/责任/改进
```
