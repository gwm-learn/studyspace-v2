# 电源与 PoE

> 解决什么问题：整机供电、模组峰值电流、PoE 线损、上下电时序、纹波干扰射频。
> 不解决：具体电源芯片选型（按厂商 datasheet）。

## 1. 电源链

```text
AC/DC 或 PoE → 保护/滤波 → DCDC → LDO → 负载
                              ├─ SoC/DDR
                              ├─ Wi-Fi/PHY
                              ├─ Modem
                              └─ USB/外设
```

### 1.1 LDO vs DCDC

| 项 | LDO | DCDC |
|---|---|---|
| 效率 | 低（压差大时更差） | 高（80–95%） |
| 噪声 | 低 | 有开关纹波 |
| 外围 | 少 | 电感/电容/布局要求高 |
| 适用 | 射频/模拟/小电流 | 主电源/大电流 |

LDO 功耗：`P_loss = (Vin - Vout) × Iout`。压差大/电流大时发热严重。

### 1.2 关键参数

| 参数 | 说明 |
|---|---|
| 输入范围 | 电池/适配器/PoE 波动 |
| 输出精度 | SoC/射频要求 |
| 纹波 | 射频/ADC 敏感 |
| 瞬态响应 | 负载突变（模组发射） |
| 效率 | 热与续航 |
| 保护 | OCP/OVP/OTP/短路 |

## 2. 功耗预算

| 负载 | 典型 | 峰值 | 备注 |
|---|---:|---:|---|
| SoC | 2 W | 5 W | 满载/降频 |
| DDR/Flash | 0.5 W | 1 W | — |
| Wi-Fi | 1 W | 3 W | 发射瞬间 |
| 5G 模组 | 2 W | 8–10 W | 发射/搜网 |
| USB | 0.5 W | 2.5 W | 外设 |
| 其他 | 0.5 W | 1 W | LED/传感器 |

设计余量：**≥30%**；峰值按实测，不只看平均。

## 3. PoE

### 3.1 标准

| 标准 | PSE 端口功率 | PD 可用功率 | 典型 |
|---|---:|---:|---|
| 802.3af (Type 1) | 15.4 W | 12.95 W | AP/普通 ODU |
| 802.3at (Type 2) | 30 W | 25.5 W | Wi-Fi 6/5G ODU |
| 802.3bt Type 3 | 60 W | 51 W | 多射频 |
| 802.3bt Type 4 | 90 W | 71 W | 加热/多模组 |

### 3.2 流程

```text
检测（Detection） → 分级（Classification） → 供电 → 维持/监控 → 断开
```

- PSE 先加小电压检测 PD 的 25 kΩ 特征。
- 分级决定可用功率；不匹配可能不供电或断电。
- 支持 LLDP 协商的 PSE/PD 可动态分配功率。

### 3.3 线损

网线电阻导致压降：

```text
V_drop = I × R_cable
P_loss = I² × R_cable
```

- Cat5e/Cat6 每对约 0.09–0.11 Ω/m；PoE 用两对/四对。
- 长线 + 大电流 → PD 端电压可能低于工作范围。
- 例：`I=1 A`、回路电阻 `20 Ω` → 压降 20 V，不可接受；必须缩短/加粗/提高 PSE 电压。

### 3.4 保护

- 浪涌/雷击：GDT/TVS/压敏 + 保险丝/PPTC。
- 热插拔：浪涌电流限制。
- 短路/过流/过温保护。
- 室外口等电位/接地。

## 4. 上下电时序

| 顺序 | 目的 |
|---|---|
| 主电源 → DDR → SoC → 外设 | 避免闩锁/误启动 |
| 断电反向 | 避免反灌 |
| 复位释放 | 在电源稳定后 |
| 模组供电 | 先供电再枚举/上电 |

错误时序会导致：不启动、枚举失败、DDR 训练失败、射频异常。

## 5. 测量

```bash
# 纹波（示波器 AC 耦合、20 MHz 带宽限制）
# 峰值电流（电流探头/电流表）
# 温升（热像仪/热电偶）
```

| 项 | 判据 |
|---|---|
| 空载/满载电压 | 规格内 |
| 纹波 | 按器件要求（常 <50 mVpp） |
| 峰值电流 | 不超电源/线缆能力 |
| 温升 | 结温留余量 |
| 上下电 | 100 次无异常 |

## 6. 常见故障

| 现象 | 原因 |
|---|---|
| 满载复位 | 峰值电流/压降/保护 |
| 模组反复枚举 | USB 供电不足/线损 |
| Wi-Fi 发射掉线 | 电源瞬态/纹波 |
| PoE 不供电 | 分级/检测/线缆 |
| 夏天重启 | 热/效率/余量 |
| 上电偶发不启动 | 时序/复位/电源爬升 |
