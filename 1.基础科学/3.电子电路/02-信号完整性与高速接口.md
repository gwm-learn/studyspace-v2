# 信号完整性与高速接口

> 解决什么问题：USB3 枚举失败、PCIe 训练失败、千兆网丢包、DDR 不稳定，究竟是硬件还是驱动。
> 不解决：具体芯片的 PHY 调参（按厂商指南）。

## 1. 传输线视角

当走线长度与信号上升沿可比时，必须按传输线处理：

```text
t_r < 2 × t_prop × length  → 需要阻抗控制
```

- 传播速度：`v ≈ c / sqrt(εr)`；FR4 `εr≈4.2`，约 `15 cm/ns`。
- 特性阻抗：单端 50 Ω、差分 90/100 Ω（USB/PCIe/以太网）。
- 反射系数：`Γ = (ZL - Z0)/(ZL + Z0)`；匹配时 `Γ=0`。

## 2. 反射与端接

| 端接 | 用途 |
|---|---|
| 源端串联 | 点对点，抑制二次反射 |
| 终端并联 | 总线/多负载 |
| 戴维南 | 兼顾功耗/匹配 |
| AC 耦合 | 不同共模电平（PCIe/SATA） |

症状：过冲/下冲/振铃/台阶。严重时误触发/训练失败。

## 3. 串扰

- 容性/感性耦合；平行长度越长、间距越小越严重。
- 近端串扰（NEXT）/远端串扰（FEXT）。
- 对策：增大间距、地屏蔽、差分、减少平行长度、完整参考平面。

经验：差分对间至少 3W，单端线间至少 3W；具体按叠层/仿真。

## 4. 参考平面与回流

- 回流走阻抗最低路径，通常在信号线正下方。
- 跨分割 → 回流绕远 → 环路变大 → 辐射/串扰/阻抗突变。
- 过孔换层时，回流地孔要靠近信号孔。
- 连接器/屏蔽罩接地要低阻抗。

## 5. 差分信号

| 项 | 要点 |
|---|---|
| 等长 | 对内偏斜控制（USB3/PCIe 很严） |
| 等距 | 保持差分阻抗 |
| 共模 | 共模扼流圈抑制 |
| 过孔 | 成对、少换层 |
| AC 耦合 | PCIe 需要 |

## 6. 眼图与抖动

- 眼高：噪声/幅度余量。
- 眼宽：时序余量。
- 抖动：随机（RJ）+ 确定性（DJ）；总抖动 TJ。
- 判定：按接口规范模板（mask）测试。

## 7. 去耦与电源完整性

- 电源分配网络（PDN）阻抗要低。
- 去耦电容：大电容（低频）+ 小电容（高频），靠近引脚。
- 开关电源环路小，避免噪声耦合到高速线。
- DDR 的 VREF/电源纹波直接影响训练。

## 8. 常见接口要点

### 8.1 USB3

- SS 差分对（TX/RX）独立，阻抗 90 Ω。
- VBUS 压降/瞬态；ESD 靠近接口。
- 2.4G 干扰：USB3 扩频/屏蔽/远离天线。

### 8.2 PCIe

- REFCLK 100 MHz 差分；PERST# 时序。
- lane 极性可反转；AC 耦合电容靠近发送端。
- 链路训练失败先查参考时钟/供电/复位。

### 8.3 以太网

- 变压器隔离、中心抽头、MDI 差分 100 Ω。
- 千兆四对；PoE 与数据共用变压器。
- 丢包查线缆/变压器/PHY/驱动。

### 8.4 DDR

- 等长/飞行时间；VREF/电源纹波。
- 训练失败查颗粒/拓扑/电源/温度。
- 降频可验证是否为 SI 问题。

## 9. 测量与定位

| 工具 | 用途 |
|---|---|
| 示波器（高带宽） | 眼图/过冲/抖动 |
| TDR | 阻抗/断点 |
| VNA | S 参数/回波损耗 |
| 协议分析仪 | 链路训练/枚举 |
| 热像仪 | 异常发热 |

定位顺序：

1. 电源/地/时钟。
2. 阻抗/端接/AC 耦合。
3. 眼图/抖动/串扰。
4. 固件均衡/预加重/驱动配置。

## 10. 常见故障

| 现象 | 首查 |
|---|---|
| USB3 只跑 USB2 | SS 对/阻抗/连接器 |
| PCIe 不识别 | REFCLK/PERST/供电 |
| 千兆降百兆 | 线缆/变压器/PHY |
| DDR 偶发错误 | 电源/时序/温度 |
| 辐射超标 | 共模/回流/时钟 |
