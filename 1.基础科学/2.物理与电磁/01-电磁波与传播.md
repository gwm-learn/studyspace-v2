# 电磁波与传播

> 解决什么问题：为什么 5 GHz 穿墙差、为什么雨天 28 GHz 掉得快、为什么“天线更高”能显著改善覆盖。
> 不解决：具体天线选型（见 [天线与链路预算](../../4.通信科学/3.射频与天线/01-链路预算与EIRP.md)）。

## 1. 基本关系

```text
c = λ f
```

- `c ≈ 3×10^8 m/s`。
- 频率越高，波长越短：绕射/穿透能力下降，可用带宽增加。
- 常见波长：2.4 GHz ≈ 12.5 cm；5 GHz ≈ 6 cm；28 GHz ≈ 1.07 cm。

自由空间波阻抗：

```text
η0 = sqrt(μ0/ε0) ≈ 377 Ω
```

## 2. 自由空间损耗（Friis）

```text
Pr = Pt * Gt * Gr * (λ / (4πd))²
```

对数形式：

```text
Pr(dBm) = Pt(dBm) + Gt(dBi) + Gr(dBi) - FSPL(dB)
FSPL(dB) = 32.44 + 20log10(f_MHz) + 20log10(d_km)
```

例子：`f=2400 MHz`、`d=1 km`：

```text
FSPL = 32.44 + 20log10(2400) + 20log10(1)
     ≈ 32.44 + 67.6 = 100.0 dB
```

同样距离 `f=5800 MHz`：约 `107.7 dB`；`f=28 GHz`：约 `121.4 dB`。**高频靠更近/更高增益天线补偿**。

## 3. 传播机制

| 机制 | 说明 | 影响 |
|---|---|---|
| 直射（LOS） | 无遮挡 | 最稳定 |
| 反射 | 地面/墙面/金属 | 多径、干涉 |
| 绕射 | 边缘/屋顶 | 遮挡后仍可覆盖 |
| 散射 | 粗糙表面/雨滴 | 能量扩散 |
| 吸收 | 水汽/氧气/树叶 | 高频更明显 |

### 3.1 多径与衰落

- 多径导致幅度/相位叠加：深衰落可能掉 20–30 dB。
- 时延扩展 `τ` 导致符号间干扰（ISI）；相干带宽 `Bc ≈ 1/(5τ)`。
- 多普勒 `fd = v f / c`；高速移动/高频更严重。
- 对抗：OFDM、均衡、分集、MIMO、交织。

### 3.2 菲涅尔区

- 第一菲涅尔区半径：`r1 = sqrt(λ d1 d2 / (d1+d2))`。
- 至少保持 60% 第一菲涅尔区无遮挡，才接近自由空间。
- 工程：天线高度、路由规划要看净空，不只看“视距”。

### 3.3 雨衰与大气

- 雨衰随频率升高急剧增加（Ku/Ka 波段明显）。
- 氧气吸收在 60 GHz 附近有峰值；水汽在 22 GHz 附近。
- 链路预算要留雨衰/衰落余量。

## 4. 室内/室外差异

| 场景 | 特点 | 设计 |
|---|---|---|
| 室内 | 多径丰富、穿透损耗大 | 多 AP、5G 优先、避金属 |
| 城区 | 建筑遮挡/反射 | 基站高度、方向角 |
| 郊区/农村 | 视距为主 | 高增益定向、远距离 |
| 沿海 | 海面反射/盐雾 | 分集、防腐蚀 |

穿透损耗经验（示例，实际按材料测）：混凝土 10–20 dB、玻璃 3–10 dB、金属 >20 dB。

## 5. 链路预算示例

```text
Pt = 20 dBm
Gt = 10 dBi
Gr = 10 dBi
f = 5.8 GHz, d = 2 km
FSPL ≈ 113.7 dB
Pr = 20 + 10 + 10 - 113.7 = -73.7 dBm
```

若接收灵敏度 `-85 dBm`，余量约 `11.3 dB`；再扣雨衰/墙体/接头，可能不够。工程上要留 10–20 dB。

## 6. 测量与验证

```bash
# Wi-Fi 侧
iw dev wlan0 survey
iw dev wlan0 station dump

# 蜂窝侧（工具/AT）
RSRP / RSRQ / SINR
```

- 频谱仪看干扰与占用。
- 路测看覆盖、切换、SINR。
- 记录天气/遮挡/天线高度，否则数据不可复现。

## 7. 常见误区

| 误区 | 纠正 |
|---|---|
| 视距就一定能通 | 菲涅尔区/雨衰/干扰 |
| 功率加倍覆盖加倍 | 只是 +3 dB，非线性 |
| 高频只是“距离短” | 穿透/雨衰/绕射都差 |
| 天线越高越好 | 可能越区覆盖/干扰 |
| 室内靠穿墙 | 多 AP 更现实 |
