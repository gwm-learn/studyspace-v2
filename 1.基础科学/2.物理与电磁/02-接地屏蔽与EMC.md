# 接地、屏蔽与 EMC

> 解决什么问题：辐射超标、ESD 复位、雷击损坏、Wi-Fi/蜂窝底噪高、USB3 干扰 2.4G。
> 不解决：具体认证流程（见 [认证与入库](../../11.应用与案例/3.测试与认证/01-认证与入库.md)）。

## 1. 三个基本概念

### 1.1 接地

| 类型 | 作用 | 注意 |
|---|---|---|
| 保护地（PE） | 人身/防雷 | 与机壳/大地低阻连接 |
| 机壳地 | 屏蔽/静电泄放 | 低阻抗、多点搭接 |
| 信号地 | 回流路径 | 参考平面连续 |
| 模拟/数字地 | 噪声隔离 | 单点/分区，不是“随便割” |

- 低频（<1 MHz）可单点接地，避免地环路。
- 高频（>1 MHz）多点接地，降低地阻抗。
- 地环路会拾取磁通变化，产生共模干扰。

### 1.2 屏蔽

- 屏蔽效能 = 反射损耗 + 吸收损耗。
- 孔缝是主要泄漏源：缝长接近 `λ/2` 时泄漏显著。
- 电缆屏蔽层必须 **360° 接地**，不能只接“猪尾巴”。
- 屏蔽罩要与地平面多点搭接；导电泡棉/屏蔽胶条要压缩到位。

### 1.3 滤波

| 位置 | 器件 |
|---|---|
| 电源入口 | 共模电感、X/Y 电容、TVS |
| 高速接口 | 共模扼流圈、ESD 阵列 |
| 时钟/复位 | RC/磁珠、串联电阻 |
| 电机/继电器 | 续流二极管、RC 吸收 |

## 2. EMC 两类问题

| 类型 | 表现 | 测试 |
|---|---|---|
| 发射（EMI） | 辐射/传导超标 | 天线/接收机、LISN |
| 抗扰（EMS） | ESD/浪涌/脉冲群导致复位/死机 | 静电枪、浪涌发生器、EFT |

### 2.1 辐射发射

常见源：

- 开关电源的开关节点/环路。
- 高速差分线的共模分量。
- 时钟谐波、DDR、USB3、PCIe。
- 电缆当作天线（共模电流）。

抑制顺序：**源 → 路径 → 受体**。先减小环路/边沿，再屏蔽/滤波，最后改布局。

### 2.2 传导发射

- 电源线上的差模/共模噪声。
- 需要 LISN 测试；整改靠输入滤波、Y 电容、共模电感、屏蔽。

### 2.3 ESD

- 放电路径：接口 → TVS → 地 → 机壳。
- 常见错误：TVS 离接口太远、地回路太长、信号线无保护。
- 复位/死机要查：复位线、电源跌落、地弹、软件看门狗。

### 2.4 浪涌/雷击

- 室外口（PoE、天线、电话线）必须做浪涌保护。
- 保护器件要配合：GDT/TVS/压敏电阻 + 保险丝/PPTC。
- 接地与等电位是基础；只加 TVS 不接地没用。

## 3. PCB 与结构实践

- 高速线参考平面完整，避免跨分割。
- 差分对等长/等距，少过孔；回流地孔靠近信号孔。
- 开关电源环路最小，输入电容靠近开关管。
- 晶振远离接口/板边，包地。
- 连接器处做 ESD/滤波，尽量靠近入口。
- 机壳缝隙/开孔控制尺寸；必要时加屏蔽/导电衬垫。
- 线缆屏蔽层与机壳 360° 搭接，避免“猪尾巴”。

## 4. 预测试与定位

| 工具 | 用途 |
|---|---|
| 近场探头 + 频谱仪 | 找辐射源 |
| 电流探头 | 找共模电流 |
| 静电枪 | ESD 预测试 |
| 浪涌/EFT 发生器 | 抗扰预测试 |
| 热像仪 | 找异常发热/器件 |

定位步骤：

1. 确认超标频点/阶次（时钟谐波？开关频率？）。
2. 拔线/断电模块，二分定位。
3. 近场探头扫板/线缆。
4. 改源/路径，再复测。

## 5. 常见故障与对策

| 现象 | 可能原因 | 对策 |
|---|---|---|
| 30–100 MHz 辐射高 | 开关电源/时钟 | 减小环路、RC 吸收、屏蔽 |
| 2.4G 底噪高 | USB3/DC-DC/屏线 | 屏蔽、滤波、改布局 |
| ESD 打接口复位 | TVS/地/复位 | 靠近接口加 TVS、改地 |
| 网口雷击损坏 | 无浪涌保护/接地 | 加 SPD、等电位 |
| 辐射随线缆变化 | 共模电流 | 共模电感、磁环、屏蔽接地 |

## 6. 检查表

- [ ] 电源入口有共模/差模滤波与 TVS。
- [ ] 室外接口有浪涌保护与接地。
- [ ] 高速线参考平面完整，回流路径短。
- [ ] 连接器屏蔽层 360° 接地。
- [ ] 晶振/时钟远离板边与接口。
- [ ] 样机做过预扫描/ESD 预测试。
- [ ] 认证版本与量产版本一致。
