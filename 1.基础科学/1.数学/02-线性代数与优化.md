# 线性代数与优化

> 解决什么问题：多天线/信道估计/功率控制/调度背后的数学；看懂 `H`、秩、SVD、注水。
> 不解决：具体 3GPP 过程（见 [NR 物理层](../../4.通信科学/2.蜂窝与终端/15-NR物理层.md)）。

## 1. 向量与矩阵

| 概念 | 工程含义 |
|---|---|
| 向量 | 一组采样/天线信号 |
| 矩阵 | 线性变换/信道 |
| 转置/共轭转置 | `H^T` / `H^H` |
| 秩 rank | 独立空间流数上限 |
| 行列式 | 体积缩放；可逆性 |
| 特征值 | 能量/稳定性 |
| 条件数 | 数值稳定性；越大越难解 |

## 2. MIMO 信号模型

```text
y = H x + n
```

- `x`：发送向量（Nt 根天线）。
- `y`：接收向量（Nr 根天线）。
- `H`：Nr×Nt 信道矩阵。
- `n`：噪声向量。

### 2.1 容量

```text
C = log2 det(I + (SNR/Nt) H H^H)   [bps/Hz]
```

- 空间流数 ≤ `min(Nr, Nt)`，且受秩限制。
- 低 SNR 时功率比空间复用更重要；高 SNR 时复用增益更明显。

### 2.2 SVD 与波束赋形

```text
H = U Σ V^H
```

- `V` 的列是发送波束方向。
- `U` 的列是接收合并方向。
- `Σ` 的对角元是各空间流的增益。

工程含义：波束赋形不是“多加天线”，而是让能量对准信道的主特征方向。

## 3. 最小二乘与信道估计

```text
min_x ||Ax - b||²
x = (A^H A)^(-1) A^H b
```

- 导频估计常用 LS/MMSE。
- `A^H A` 条件数差时，解不稳定 → 需要正则化（岭回归）。
- 工程上要关注导频密度、噪声、干扰。

## 4. 凸优化

### 4.1 形式

```text
min f0(x)
s.t. fi(x) ≤ 0, hi(x) = 0
```

- 凸目标 + 凸约束 → 局部最优即全局最优。
- 非凸问题（如功率分配、用户调度）通常需要近似/分解/搜索。

### 4.2 拉格朗日与 KKT

```text
L(x,λ,ν) = f0(x) + Σ λi fi(x) + Σ νi hi(x)
```

KKT 条件给出最优性必要条件；工程上常用于推导功率分配/注水。

### 4.3 注水（water-filling）

在总功率约束下最大化容量：

```text
Pi = max(0, μ - 1/λi)
```

- `λi`：子信道增益。
- `μ`：水位，由总功率确定。
- 差信道不分配功率；好信道多分配。

## 5. 工程应用

| 场景 | 数学工具 |
|---|---|
| MIMO/波束赋形 | SVD、特征值 |
| 信道估计 | 最小二乘/MMSE |
| 功率控制 | 凸优化/注水 |
| 调度 | 优化/贪心/公平性 |
| 干扰对齐 | 子空间/零空间 |
| 链路预算 | 对数域线性化 |

## 6. 数值例子（2×2）

若 `H = [[1,0],[0,0.5]]`，则两个空间流增益分别为 1 和 0.5；第二流在低 SNR 下可能关闭，把功率让给第一流。工程上表现为“阶数/流数自适应”。

## 7. 常见误区

| 误区 | 纠正 |
|---|---|
| 天线越多速率越高 | 受秩/相关性/终端能力限制 |
| 功率越大越好 | 干扰/功耗/线性度 |
| 信道估计可以忽略 | 估计误差直接损失容量 |
| 优化一定求全局最优 | 非凸问题通常只能近似 |

## 8. 实验

1. 用 Python/NumPy 生成 `H`，计算 SVD、容量、条件数。
2. 改变天线相关性，观察秩/容量变化。
3. 实现注水算法，对比等功率分配。
4. 用不同 SNR 画容量曲线。
