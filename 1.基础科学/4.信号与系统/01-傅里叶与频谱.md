# 傅里叶与频谱

> 解决什么问题：看干扰、选滤波、理解带宽/边带/谐波，以及频谱仪读数为什么和理论不一样。
> 不解决：具体射频链路设计（见 [射频与天线](../../4.通信科学/3.射频与天线/00-总览.md)）。

## 1. 从时域到频域

任何满足条件的信号可分解为正弦/复指数叠加：

```text
x(t) = Σ ak e^(j2πkf0t)          （周期信号，傅里叶级数）
X(f) = ∫ x(t) e^(-j2πft) dt      （非周期，傅里叶变换）
```

工程直觉：

- 时域变化越快 → 高频分量越多。
- 频域越宽 → 时域边沿越陡。
- 带宽与上升时间近似：`BW ≈ 0.35 / t_r`。

## 2. 离散与 FFT

- DFT：`X[k] = Σ x[n] e^(-j2πkn/N)`。
- FFT 是 DFT 的快速算法，复杂度 `O(N log N)`。
- 频率分辨率：`Δf = fs / N`；`N` 越大分辨率越高，但时间窗更长。
- 采样率必须满足奈奎斯特：`fs ≥ 2 fmax`，否则混叠。

### 2.1 窗函数

| 窗 | 特点 | 用途 |
|---|---|---|
| 矩形 | 分辨率高、泄漏大 | 瞬态/整周期 |
| Hann | 泄漏小、分辨率略降 | 通用 |
| Blackman | 泄漏更小 | 小信号/谐波 |
| Flat-top | 幅度准确 | 校准 |

泄漏来自“截断后不是整周期”。加窗可减小旁瓣，但会展宽主瓣。

## 3. 常用指标

| 指标 | 含义 |
|---|---|
| 带宽 | 占用频谱宽度 |
| 谐波 | `n×f0` 处的杂散 |
| 杂散 | 非谐波离散峰 |
| 相位噪声 | 载波附近的随机抖动 |
| 占用带宽（OBW） | 含指定功率百分比的带宽 |
| 邻道泄漏（ACLR） | 相邻信道泄漏 |

dB 换算：

```text
dBm = 10log10(P/1mW)
dB  = 10log10(P1/P2)
电压比 = 20log10(V1/V2)
```

## 4. 频谱仪怎么读

- `RBW`：分辨率带宽，越小噪声底越低、扫描越慢。
- `VBW`：视频带宽，平滑显示。
- 检波器：峰值/平均/准峰值；认证按标准。
- 噪声底 = `-174 dBm/Hz + 10log10(RBW) + NF`（近似）。
- 近场探头能定位源，但不能替代正式测试。

例子：RBW=100 kHz 时噪声底约 `-174 + 50 = -124 dBm`（加 NF 后更高）。

## 5. 工程应用

| 场景 | 看什么 |
|---|---|
| 电源干扰 | 开关频率及谐波 |
| Wi-Fi 2.4G 底噪 | USB3/DC-DC/屏线 |
| 时钟辐射 | 时钟谐波/边带 |
| 滤波器 | 截止/滚降/插损 |
| 调制质量 | 占用带宽/ACLR/EVM |

## 6. 常见误区

| 误区 | 纠正 |
|---|---|
| 频谱峰值就是干扰源 | 可能是谐波/互调 |
| RBW 越小越好 | 噪声底下降但扫描慢 |
| 平均检波适合所有标准 | 认证按检波方式 |
| 看到单峰就是纯正弦 | 可能是调制/噪声 |
| 频谱仪带宽足够 | 前端/衰减/混叠也要看 |

## 7. 实验

1. 用 Python 生成方波/调幅波，做 FFT，观察谐波/边带。
2. 改变窗函数，观察泄漏。
3. 用信号源+频谱仪测 RBW/噪声底。
4. 用近场探头找板子上的辐射源。
