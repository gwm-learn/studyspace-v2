# 调制、采样与噪声

> 解决什么问题：为什么高阶 QAM 只在近点可用、为什么灵敏度差 3 dB 覆盖明显变小、EVM 差该查什么。
> 不解决：具体 802.11/3GPP 调制编码表（见各自协议）。

## 1. 为什么调制

- 把基带信号搬到射频，匹配天线/传播。
- 用幅度/相位/频率携带信息。
- 多载波/扩频提高抗干扰与多址能力。

## 2. 模拟与数字调制

| 类型 | 例子 | 特点 |
|---|---|---|
| 幅度 | AM/ASK | 简单，抗噪差 |
| 频率 | FM/FSK | 恒包络，抗幅度噪声 |
| 相位 | PSK | 频谱效率较高 |
| 幅相 | QAM | 效率高，需高 SNR |
| 多载波 | OFDM | 抗多径，PAPR 高 |
| 扩频 | DSSS/OFDM | 抗干扰/多址 |

### 2.1 QAM 与星座图

- 16QAM：4 bit/symbol；64QAM：6 bit/symbol；256QAM：8 bit/symbol；1024QAM：10 bit/symbol。
- 阶数越高，星座点越密，对噪声/相位噪声/EVM 越敏感。
- 实际系统按 SNR/信道质量自适应 MCS。

### 2.2 OFDM

- 多个正交子载波并行；子载波间隔 `Δf`。
- 符号长度 `T=1/Δf`；循环前缀（CP）抗多径。
- 优点：抗频率选择性衰落、均衡简单。
- 缺点：PAPR 高（功放回退）、对频偏/相位噪声敏感。

## 3. 采样与量化

- 奈奎斯特：`fs ≥ 2 fmax`。
- 欠采样 → 混叠；抗混叠滤波必须在 ADC 前。
- 量化噪声：SNR ≈ `6.02N + 1.76 dB`（满幅正弦）。
- 过采样 + 数字滤波可提高有效位数。

## 4. 噪声与链路指标

| 指标 | 定义 | 工程意义 |
|---|---|---|
| SNR | 信号/噪声 | 解调质量 |
| SINR | 信号/(噪声+干扰) | 真实无线环境 |
| NF | 噪声系数 | 接收链路恶化 |
| 灵敏度 | 最低可解调功率 | 覆盖边缘 |
| EVM | 误差向量幅度 | 发射/接收调制质量 |
| PAPR | 峰均比 | 功放回退/效率 |

灵敏度近似：

```text
Sensitivity(dBm) = -174 + 10log10(BW) + NF + SNR_required
```

例：`BW=20 MHz`、`NF=5 dB`、`SNR=10 dB`：

```text
-174 + 73 + 5 + 10 = -86 dBm
```

## 5. EVM 与常见损伤

| 损伤 | 表现 | 首查 |
|---|---|---|
| 相位噪声 | 星座旋转/扩散 | 本振/时钟 |
| IQ 不平衡 | 星座椭圆/镜像 | 调制器/校准 |
| 非线性 | 高阶星座压缩 | 功放回退 |
| 直流偏移 | 中心偏移 | ADC/前端 |
| 频偏 | 整体旋转 | 参考时钟 |
| 多径 | 频率选择性失真 | 均衡/天线 |

## 6. 编码与交织

- 卷积码/LDPC/Polar 提供纠错增益。
- 交织抗突发错误。
- 编码增益可换更低的 SNR 门限或更高速率。
- 工程上“速率上不去”可能是码率/MCS 被保守选择，不一定是射频坏。

## 7. 工程应用

| 场景 | 关注 |
|---|---|
| Wi-Fi 边缘 | MCS 降阶、重传 |
| 5G 近点 | 高阶 QAM/带宽 |
| 功放设计 | PAPR/回退/效率 |
| 接收灵敏度 | NF/带宽/干扰 |
| 测试 | EVM/ACLR/灵敏度 |

## 8. 常见误区

| 误区 | 纠正 |
|---|---|
| 天线增益越高越好 | 波束窄、覆盖形状变差 |
| 功率越大速率越高 | 受 SNR/干扰/线性度限制 |
| EVM 差就是天线 | 更多是本振/电源/功放 |
| 采样率够就不会混叠 | 前端滤波/带宽也要够 |
| 灵敏度只看芯片 | 前端插损/干扰也关键 |

## 9. 实验

1. 用 Python 生成 QPSK/16QAM，加噪声，画星座/EVM。
2. 改变 SNR，观察误码率。
3. 用信号源+频谱仪看 OFDM 占用带宽/ACLR。
4. 在设备上读 MCS/RSRP/SINR，对照吞吐。
