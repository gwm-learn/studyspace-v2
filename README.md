## 三条阅读主线

1. **一个包的一生**：射频/空口 → PHY/MAC → 驱动 → 内核网络栈 → Netfilter/NAT → 转发 → 应用。
2. **一次入网**：SIM → Modem → 入网信令 → QMI/MBIM → rmnet/IPA → NAT → 业务。
3. **一次升级**：镜像 → U-Boot → Kernel/DTB → RootFS → 配置/overlay → 回滚。

每条主线的跳转表在 [知识框架图](0.框架/知识框架图.md)。

## 分层约定（避免重复）

| 层 | 写什么 | 不写什么 |
|---|---|---|
| L1 理论 | 概念、模型、协议规范 | 配置步骤、平台细节 |
| L2 实现 | 内核/驱动/用户态实现 | 重抄 L1 |
| L3 工程 | 配置、抓包、验证、排错 | 重抄 L1/L2 |
| L4 应用 | 项目、认证、产线、运维 | 重抄技术原理 |

> 同一主题的 L1–L4 由该主题的 Hub 统一索引；跨层只链接，不复制。

## 明确不采用的四种组织方式

1. ❌ 以 OpenWrt 为中心（它只是 `7.平台与集成/1.OpenWrt`）。
2. ❌ 以项目周期/学习天数为中心（项目在 `11.应用与案例`）。
3. ❌ 以厂商/芯片型号为顶层（型号会淘汰）。
4. ❌ 以“资料类型”为顶层（PDF/源码/笔记混放）。
