# 实用技巧


## sudo 执行shell脚本


sudo vim /etc/sudoers，并在文件内增加这么一行:Defaults secure_path=”/bin:/usr/bin:/usr/local/bin:…”, 把要用的命令path包括进去。

## 内网内传输数据


```
scp -r -P [端口号] [源用户]@[源主机IP]:/[源目录路径] [本地目标路径]
```

```
rsync -av --progress -e "ssh -c aes128-ctr" scpuser@服务器IP:/data/ /本地目录/
```
