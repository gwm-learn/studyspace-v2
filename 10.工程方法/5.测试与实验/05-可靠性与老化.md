# 可靠性与老化

> 解决什么问题：长期运行/高温/弱网/异常下是否稳定；如何设计老化与判定。
> 不解决：具体产品 MTBF 计算（需现场数据）。

## 1. 测试项

| 项 | 方法 | 判据 |
|---|---|---|
| 长时间 | 72 h 流量 | 无重启/泄漏 |
| 反复上下电 | 50–100 次 | 每次启动 |
| 高温 | 满载 8–24 h | 不降速/死机 |
| 弱网 | tc netem | 可恢复 |
| 异常 | 拔线/断电/满盘 | 自恢复 |
| 老化 | 产线 4–24 h | 无早期失效 |

## 2. 监控

| 指标 | 工具 |
|---|---|
| 重启/看门狗 | 日志/计数器 |
| 内存 | `free`/`/proc/meminfo` |
| 温度 | thermal/hwmon |
| 连接/表项 | conntrack/路由 |
| 日志 | 本地环形/远程 syslog |

## 3. 弱网模拟

```bash
tc qdisc add dev eth0 root netem delay 100ms loss 1% reorder 0.5%
tc qdisc change dev eth0 root netem delay 300ms loss 5%
tc qdisc del dev eth0 root
```

观察：重连/保活/超时/业务恢复。

## 4. 上下电

- 冷启动/热重启/硬断电。
- 反复 50–100 次。
- 检查文件系统/分区/配置/校准数据。
- 记录失败次数/现象。

## 5. 高温

- 烘箱/密闭外壳/满载。
- 记录 SoC/PA/电源/模组温度。
- 观察降频/掉速/重启。
- 高温后复测功能。

## 6. 异常恢复

| 异常 | 预期 |
|---|---|
| 拔 WAN | 自动重拨/恢复 |
| 断 upstream | 切换/重连 |
| 满盘 | 日志滚动/告警 |
| 进程崩溃 | 看门狗/重启 |
| 断电 | 配置不丢/可启动 |

## 7. 老化与 MTBF

- 老化筛早期失效（浴盆曲线）。
- MTBF 需现场/加速寿命数据，不是拍脑袋。
- 记录批次/器件/温度/失效模式。

## 8. 常见问题

| 现象 | 原因 |
|---|---|
| 3 天后变慢 | 内存泄漏/表项 |
| 夏天重启 | 热余量不足 |
| 断电不启动 | 文件系统/分区 |
| 弱网不恢复 | 重连/保活缺失 |
| 老化后失效 | 早期失效/散热 |
