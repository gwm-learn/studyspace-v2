# 射频与天线

> 解决什么问题：信号为什么覆盖不到、EIRP 怎么算、天线怎么选/怎么装。

## 1. 核心概念

| 概念 | 说明 |
|---|---|
| 频段/带宽 | 传播特性、许可、干扰 |
| 发射功率 | 传导功率 + 天线增益 − 损耗 = EIRP |
| 天线增益/波束 | dBi，越高波束越窄 |
| 极化 | 单/双极化，需与对端匹配 |
| 驻波/回波损耗 | 天线与馈线匹配 |
| 路径损耗 | 距离、频率、遮挡、雨衰 |
| 接收灵敏度 | 决定边缘覆盖 |

## 2. 链路预算

```text
接收功率 = 发射功率 + 发射增益 − 路径损耗 + 接收增益 − 馈线/接头损耗
```

## 3. 工程检查

- [ ] EIRP 符合当地法规与运营商要求。
- [ ] 天线极化/朝向/下倾角正确。
- [ ] 馈线损耗与接头质量。
- [ ] 避雷/接地。
- [ ] 现场用 RSRP/SINR/吞吐共同判定，不只看信号格。
