# 链路预算与 EIRP

> 解决什么问题：覆盖够不够、为什么“信号满格但速率低”、为什么换高增益天线反而变差。
> 不解决：具体运营商频率/功率规范（以当地法规与合同为准）。

## 1. 基本公式

```text
EIRP(dBm) = Pt(dBm) + Gt(dBi) - L_feed(dB)
Pr(dBm)  = EIRP + Gr(dBi) - L_path(dB) - L_misc(dB)
```

- `Pt`：发射机传导功率。
- `Gt/Gr`：发/收天线增益。
- `L_feed`：馈线/接头/避雷器损耗。
- `L_path`：路径损耗（自由空间/传播模型）。
- `L_misc`：人体/墙体/雨衰/极化失配等。

## 2. 自由空间与传播模型

```text
FSPL(dB) = 32.44 + 20log10(f_MHz) + 20log10(d_km)
```

例子：

| 频率 | 1 km | 5 km | 10 km |
|---|---:|---:|---:|
| 900 MHz | 91.5 dB | 105.5 dB | 111.5 dB |
| 2.4 GHz | 100.0 dB | 114.0 dB | 120.0 dB |
| 5.8 GHz | 107.7 dB | 121.7 dB | 127.7 dB |
| 28 GHz | 121.4 dB | 135.4 dB | 141.4 dB |

实际用 Okumura-Hata/COST-231/射线追踪修正；室内还要加穿透损耗。

## 3. 接收灵敏度

```text
Sensitivity(dBm) = -174 + 10log10(BW) + NF + SNR_req
```

例：`BW=20 MHz`、`NF=5 dB`、`SNR_req=10 dB`：

```text
-174 + 73 + 5 + 10 = -86 dBm
```

- 带宽越宽，噪声越大，灵敏度越差（但速率高）。
- 高阶调制需要更高 SNR。
- 实际还要加干扰余量/衰落余量。

## 4. 余量

| 余量 | 典型 | 说明 |
|---|---:|---|
| 衰落余量 | 6–20 dB | 多径/阴影 |
| 干扰余量 | 3–10 dB | 邻区/同频 |
| 雨衰 | 按频率/地区 | Ku/Ka 明显 |
| 人体/墙体 | 3–20 dB | 室内 |
| 设计余量 | 3–6 dB | 老化/偏差 |

> 链路预算不是“算到 0 dB 就能用”；工程上要留够余量。

## 5. 上下行分别算

- 下行：基站功率大，终端灵敏度和天线小。
- 上行：终端功率受限，基站灵敏度好；上行往往是覆盖瓶颈。
- ODU 的发射功率/天线增益受法规/运营商限制。

## 6. EIRP 与法规

- EIRP 不是越大越好：受限于法规、邻区干扰、功耗/热。
- 2.4G/5G 不同信道/频段有不同功率限制。
- 定向天线高增益 + 高功率可能超 EIRP 限制。
- 室外 ODU 还要考虑运营商许可/型号核准。

## 7. 例子：CPE 下行

```text
基站：Pt=40 dBm，Gt=15 dBi，馈线 2 dB → EIRP=53 dBm
距离 2 km，3.5 GHz：FSPL≈109.3 dB
终端：Gr=10 dBi，馈线 1 dB，墙体 10 dB
Pr = 53 - 109.3 + 10 - 1 - 10 = -57.3 dBm
```

若灵敏度 `-95 dBm`，余量约 37.7 dB；但高速率需要更高 SNR，实际可用 MCS 会下降。

## 8. 常见误区

| 误区 | 纠正 |
|---|---|
| 天线增益越高覆盖越好 | 波束窄，可能漏覆盖/超 EIRP |
| 信号满格速率就高 | 看 SINR/干扰/调度 |
| 只看下行 | 上行常是瓶颈 |
| 链路预算算通就行 | 还要留衰落/干扰余量 |
| 功率加倍距离加倍 | 只 +3 dB，非线性 |

## 9. 验证

- 现场测 RSRP/RSRQ/SINR + 吞吐。
- 改变天线方向/高度，记录变化。
- 用频谱仪看干扰/占用。
- 对比理论预算与实测，修正模型。
