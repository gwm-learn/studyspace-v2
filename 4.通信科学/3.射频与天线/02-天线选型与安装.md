# 天线选型与安装

> 解决什么问题：选错天线/装错方向导致覆盖差、速率低、驻波高、干扰大。
> 不解决：具体天线仿真/设计。

## 1. 天线参数

| 参数 | 含义 | 工程影响 |
|---|---|---|
| 增益（dBi） | 方向性收益 | 越高波束越窄 |
| 波束宽度 | 水平/垂直 | 覆盖形状/对准难度 |
| 极化 | 线/圆/双极化 | 与对端匹配 |
| 驻波比（VSWR） | 匹配程度 | >2 反射大/效率低 |
| 隔离度 | 双极化/多天线 | MIMO 效果 |
| 前后比 | 前向/后向 | 抗后向干扰 |
| 最大功率 | 耐受 | 别超 |

## 2. 选型

| 场景 | 天线 | 原因 |
|---|---|---|
| 室内覆盖 | 全向/吸顶 | 均匀覆盖 |
| 室外近距 | 板状定向 | 覆盖一角 |
| ODU 远距 | 高增益定向/栅格 | 补偿路径损耗 |
| 移动/漫游 | 全向/宽波束 | 不容易失锁 |
| 点对点 | 高增益定向 | 视距回传 |
| MIMO | 双极化/多端口 | 空间复用/分集 |

原则：

- 先算链路预算，再选增益；不要“越大越好”。
- 波束越窄，安装对准要求越高。
- 室内多 AP 通常比单点高增益更有效。

## 3. 安装

### 3.1 方位/下倾/极化

- 方位角：对准基站/对端。
- 下倾角：控制覆盖边缘/越区。
- 极化：与对端一致（±45° 或垂直/水平）。
- 用 RSRP/SINR/吞吐共同判定，不只看信号格。

### 3.2 馈线与接头

- 馈线越短越好；高频损耗大。
- 接头要防水；室外用自粘胶带 + 扎带 + 滴水弯。
- 屏蔽层/接地要可靠。
- 避免与电源线/高速线并行。

### 3.3 防雷/接地

- 天线/支架/馈线屏蔽层按规范接地。
- 室外加 SPD；等电位连接。
- 雷击损坏常因接地不良，不是天线本身。

### 3.4 结构

- 抱杆/壁挂牢固，风载留余量。
- 避免遮挡（建筑/树/金属）。
- 留维护空间；标签/照片留档。

## 4. 驻波与故障

| VSWR | 反射 | 说明 |
|---|---:|---|
| 1.0 | 0% | 理想 |
| 1.5 | 4% | 良好 |
| 2.0 | 11% | 可接受边缘 |
| >3 | >25% | 故障/严重失配 |

常见原因：接头未拧紧/进水、馈线损坏、天线内部故障、频率不匹配。

## 5. 安装验收

- [ ] 方位/下倾/极化符合规划。
- [ ] VSWR 达标。
- [ ] RSRP/SINR 达标。
- [ ] 上下行吞吐达标。
- [ ] 防水/接地/防雷完成。
- [ ] 照片/参数记录归档。

## 6. 常见误区

| 误区 | 纠正 |
|---|---|
| 增益越高越好 | 波束窄/超 EIRP/难对准 |
| 只看 RSRP | SINR/吞吐更关键 |
| 天线随便挂 | 方向/极化/遮挡影响大 |
| 驻波不用测 | 反射会伤功放/降覆盖 |
| 室内靠穿墙 | 多 AP 更可靠 |
