# 传播模型与现场勘测

> 解决什么问题：规划覆盖、判断站址/天线高度、验证“理论够但现场不行”。
> 不解决：具体运营商规划工具/参数。

## 1. 模型选择

| 模型 | 频段/场景 | 特点 |
|---|---|---|
| 自由空间 | 视距/基准 | 理想 |
| Okumura-Hata | 150–1500 MHz 宏蜂窝 | 经验 |
| COST-231 Hata | 1.5–2 GHz | 扩展 |
| COST-231 Walfisch-Ikegami | 城区 | 建筑/街道 |
| 3GPP TR 38.901 | 0.5–100 GHz | 5G 场景 |
| 射线追踪 | 室内/复杂 | 精确但慢 |

模型输出：路径损耗 → 接收功率 → 覆盖半径/边缘速率。

## 2. 关键输入

- 频率、带宽、天线高度、增益、下倾。
- 建筑密度/材料、地形、植被。
- 发射功率/EIRP、噪声/干扰。
- 终端高度/天线。

## 3. 现场勘测步骤

### 3.1 准备

- 拓扑图/平面图/经纬度。
- 设备/终端/测试卡/电源。
- 测试工具（路测软件/频谱仪/测速）。
- 记录模板。

### 3.2 测点

| 类型 | 目的 |
|---|---|
| 近点 | 峰值/上限 |
| 中点 | 典型体验 |
| 边缘 | 切换/覆盖极限 |
| 遮挡 | 穿透/绕射 |
| 干扰点 | 同频/邻频 |

### 3.3 采集

| 指标 | 说明 |
|---|---|
| RSRP | 覆盖强度 |
| RSRQ | 质量（负载/干扰） |
| SINR | 解调质量 |
| PCI/频段/带宽 | 小区信息 |
| 上下行吞吐/时延 | 体验 |
| 切换/掉线 | 移动性 |

### 3.4 记录

- 时间/地点/天气/终端/版本。
- 照片（朝向/遮挡/安装）。
- 频谱/抓包（干扰问题）。
- 结论与建议。

## 4. 覆盖与容量

| 问题 | 手段 |
|---|---|
| 覆盖不足 | 加站/升高/换高增益/降频 |
| 容量不足 | 加站/加载波/CA/分流 |
| 干扰 | 换频/调整下倾/屏蔽 |
| 越区覆盖 | 降功率/下倾/方向角 |
| 室内弱 | 室分/多 AP/窗边 |

## 5. 常见误区

| 误区 | 纠正 |
|---|---|
| 仿真够就够 | 现场遮挡/干扰差异大 |
| 只看 RSRP | SINR/负载决定速率 |
| 一个点代表全城 | 需要网格/多场景 |
| 天气无关 | 雨衰/湿度影响高频 |
| 终端无关 | 天线/能力差异大 |
