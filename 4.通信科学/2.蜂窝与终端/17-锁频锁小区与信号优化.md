# 锁频、锁小区与信号优化

> 解决什么问题：边界飘站、频繁切换、特定小区速率异常；以及“什么时候不该锁”。
> 不解决：运营商参数/邻区规划。

## 1. 为什么会飘站

- 小区覆盖交叠，终端按重选/切换门限选择。
- 信号快速波动（遮挡/移动/天气）。
- 不同频段/带宽能力差异。
- 负载/干扰导致 SINR 变化。

结果：频繁重选/切换 → 瞬时断流、速率抖动、掉线。

## 2. 锁的对象

| 对象 | 说明 | 影响 |
|---|---|---|
| Band | 频段 | 限制可用载波 |
| ARFCN/EARFCN | 频点 | 锁定特定载波 |
| PCI | 小区标识 | 锁定特定小区 |
| 带宽 | 小区带宽 | 影响速率 |
| 波束/SSB | NR 波束 | 影响覆盖 |

## 3. 常见手段

- 模组 AT 命令（厂商私有）。
- QMI/MBIM 厂商扩展。
- 平台工具/诊断接口。
- 研发模式/工程菜单。

> 命令随模组型号/固件差异很大，必须以厂商手册为准；不要把某型号命令套到另一型号。

## 4. 什么时候锁

| 场景 | 建议 |
|---|---|
| 固定 ODU/CPE | 可锁频/锁小区，减少飘站 |
| 移动终端 | 不建议锁死 |
| 测试对比 | 固定小区，排除变量 |
| 运营商要求 | 按白名单/规范 |
| 边缘覆盖 | 谨慎，锁死可能无服务 |

## 5. 风险

- 锁死无法切换：移动/遮挡时直接掉线。
- 小区退服/维护：设备无法迁移。
- 参数变更：现场无法远程调整。
- 影响运营商网络优化/投诉。

> 锁频/锁小区是“稳定器”，不是“优化万能药”。优先物理层/天线/位置。

## 6. 优化顺序

```text
1. 位置/高度/朝向/遮挡
2. 天线增益/极化/下倾
3. 频段/带宽/CA
4. 功率/波束
5. 锁频/锁小区
6. 软件重拨/看门狗
```

## 7. 验证

- 锁前/锁后各测：RSRP/SINR/吞吐/时延/切换。
- 移动/遮挡/雨天复测。
- 观察是否出现“无服务/无法恢复”。
- 记录锁参数与恢复方法。

## 8. 常见问题

| 现象 | 原因 |
|---|---|
| 锁后无服务 | 小区退服/参数错 |
| 速率反而低 | 锁到拥塞小区 |
| 无法切换 | 锁死/邻区限制 |
| 重启后失效 | 配置未持久化 |
| 远程无法解除 | 无恢复通道 |

## 9. 设计建议

- 锁参数可配置、可远程解除。
- 保留自动模式作为兜底。
- 记录锁策略与生效条件。
- 运营商入网前确认允许锁频。
