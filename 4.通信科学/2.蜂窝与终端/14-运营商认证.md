# 运营商认证与入库

> 解决什么问题：蜂窝终端/ODU 要进入运营商网络，需要过哪些门槛。
> 不解决：具体运营商的内部测试规范（需 NDA/接口人）。

## 1. 认证层次

```text
型号核准（SRRC/CE/FCC）
    │
    ▼
运营商入库测试（网络兼容/性能/安全/运维）
    │
    ▼
白名单/IMEI 报备
    │
    ▼
商用放号
```

## 2. 常见测试项

| 类别 | 项目 |
|---|---|
| 网络 | 附着、PDN、切换、重选、漫游 |
| 频段 | 支持的 band、载波聚合、带宽 |
| 性能 | 上下行吞吐、时延、并发 |
| 语音 | VoLTE/IMS（如支持） |
| 稳定性 | 长时间、弱信号、反复开关机 |
| 安全 | 默认口令、开放端口、固件签名 |
| 管理 | TR-069/TR-369、远程升级、诊断 |
| 硬件 | 天线、EIRP、SAR/MPE |

## 3. 白名单与标识

| 项 | 说明 |
|---|---|
| IMEI | 设备唯一标识；需合规分配，不可篡改 |
| IMSI | SIM 侧标识，不写入设备 |
| 型号 | 与认证/入库一致 |
| 软件版本 | 冻结版本；变更需评估 |
| TAC | IMEI 前 8 位，需申请/登记 |

> 不同运营商对 IMEI 报备、TAC 分配、样机数量要求不同，提前确认。

## 4. 送测准备

- [ ] 样机数量与配件（电源、天线、网线、SIM）。
- [ ] 固件版本、调试口令、日志抓取方式。
- [ ] 测试规范对照表（逐条自查）。
- [ ] ACS/管理平台对接参数。
- [ ] 认证报告（SRRC/CE/FCC）与标签。
- [ ] 问题接口人与升级路径。

## 5. 常见失败

| 现象 | 原因 |
|---|---|
| 无法附着 | band/APN/鉴权/白名单 |
| 速率不达标 | 天线/射频/CA/调度 |
| 切换失败 | 邻区/测量/参数 |
| VoLTE 不通 | IMS 配置/证书/编码 |
| ACS 连不上 | 地址/证书/NAT |
| 安全测试失败 | 默认口令/开放端口 |
| 版本不一致 | 送测与量产版本不同 |

## 6. 通过后的维护

- 建立"认证版本基线"，任何改动评估是否需重测。
- 保留测试报告、问题清单、整改记录。
- 与运营商保持版本/漏洞通告渠道。
- 现场问题回流到 [运维与故障案例](../../11.%E5%BA%94%E7%94%A8%E4%B8%8E%E6%A1%88%E4%BE%8B/5.%E8%BF%90%E7%BB%B4%E4%B8%8E%E6%95%85%E9%9A%9C%E6%A1%88%E4%BE%8B/00-%E6%80%BB%E8%A7%88.md)。
