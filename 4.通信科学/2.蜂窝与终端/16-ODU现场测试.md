# ODU 现场测试

> 解决什么问题：现场怎么判断“装对了、能交付、能长期稳定”，而不是“能亮灯”。
> 不解决：具体运营商验收规范（按合同/白皮书）。

## 1. 测试前准备

| 项 | 内容 |
|---|---|
| 资料 | 站点信息、频段/PCI/APN、验收标准 |
| 工具 | 笔记本/测试终端、PoE 注入器、网线、光功率计（如光纤）、指南针/角度尺 |
| 软件 | 测速、ping、traceroute、频谱（可选）、厂商诊断工具 |
| 安全 | 登高/防雷/防水/用电 |

## 2. 供电与上电

```text
PoE PSE → 网线 → ODU PD → 启动
```

检查：

- PSE 功率/分级是否匹配。
- 网线长度/线径/压降。
- 上电电流/峰值；反复重启说明供电/保护。
- 接地/防雷。

## 3. 信号与小区

| 指标 | 说明 | 记录 |
|---|---|---|
| RSRP | 覆盖强度 | dBm |
| RSRQ | 质量 | dB |
| SINR | 解调质量 | dB |
| PCI/频段/带宽 | 小区信息 | — |
| 邻区 | 切换/干扰 | — |

对准：方位角/下倾角/极化；用 RSRP + SINR + 吞吐共同判定。

## 4. 吞吐与时延

```bash
iperf3 -c <server> -t 30 -P 4
iperf3 -c <server> -t 30 -P 4 -R
ping -i 0.02 -c 1000 <gateway>
```

| 项 | 判据 |
|---|---|
| 下行/上行 | 达套餐/合同比例 |
| 时延 | 业务可接受 |
| 抖动/丢包 | 语音/游戏门槛 |
| 多终端 | 并发不崩 |

## 5. 稳定性

- 连续 ping/业务 30–60 min。
- 反复上下电 10–20 次。
- 高温/暴晒/密闭（如条件允许）。
- 弱信号边缘保持连接。
- 观察重启/掉线/温度/电流。

## 8. 常见问题

| 现象 | 首查 |
|---|---|
| 不上电 | PoE/线缆/分级 |
| 信号差 | 朝向/遮挡/频段 |
| 速率低 | SINR/拥塞/回传/终端 |
| 反复重启 | 峰值电流/线损/温度 |
| 雨天变差 | 接头进水/雨衰 |
| 无法接入 | APN/白名单/鉴权 |

## 9. 验收判定

- 覆盖/质量达门槛。
- 吞吐/时延达业务要求。
- 稳定运行无重启/掉线。
- 安装/防水/接地合格。
- 记录完整、可追溯。
