# ODU 与 IDU

> 解决什么问题：ODU（室外单元）与普通 CPE 的差异，以及整机交付必须考虑的事。
> 不解决：具体型号的射频参数与运营商规范（需查机型规格书）。

## 1. 形态

| 形态 | 组成 | 适用 |
|---|---|---|
| All-in-One CPE |  modem + Wi-Fi + 天线一体 | 室内/窗边 |
| ODU + IDU | 室外射频/ modem + 室内供电/路由 | 信号弱、需室外安装 |
| ODU 一体 | 室外 modem + PoE + 定向天线 | 无线宽带入户 |

```text
室外                                              室内
┌───────────── ODU ─────────────┐
│ 天线 → RF → Modem → PoE PD    │──网线（PoE）──┐
└───────────────────────────────┘                │
                                                 ▼
                                      ┌──── IDU / 路由器 ────┐
                                      │ PoE PSE → CPU → Wi-Fi │
                                      └───────────────────────┘
```

## 2. 供电：PoE

| 标准 | 端口功率 | 典型用途 |
|---|---|---|
| 802.3af | 15.4 W | 普通 AP/ODU |
| 802.3at | 30 W | 5G ODU、Wi-Fi 6 |
| 802.3bt | 60/90 W | 多射频、加热、远距离 |

要点：

- **线损**：网线越长、线径越细，压降越大；ODU 峰值电流可能超过平均值数倍。
- **分级**：PSE 与 PD 的 class 要匹配；不匹配可能不供电或反复重启。
- **浪涌/防雷**：室外必须做接地与防雷；PoE 口加保护。
- **加热/除霜**：寒冷地区 ODU 可能需要加热，功耗要预留。
- **线缆**：户外用防水接头、UV 防护、阻燃等级。

## 3. 天线与链路预算

| 参数 | 说明 |
|---|---|
| 增益 | dBi，越高波束越窄 |
| 波束宽度 | 水平/垂直，决定对准难度 |
| 极化 | 单极化/双极化，需与基站匹配 |
| EIRP | 发射功率 + 天线增益 − 馈线损耗 |
| 频段 | 运营商许可，决定传播特性 |

简化链路预算：

```text
接收功率 = 发射功率 + 发射增益 − 路径损耗 + 接收增益 − 馈线/接头损耗
```

路径损耗与频率、距离、遮挡、雨衰有关；实际以现场测量为准。

**对准**：方位角、下倾角、极化角；用 RSRP/SINR 与吞吐共同判定，不要只看 RSRP。

## 4. 安装

- [ ] 抱杆/壁挂牢固，风载计算留余量。
- [ ] 天线朝向避开遮挡与强干扰源。
- [ ] 防水：接头朝下、缠防水胶带、滴水弯。
- [ ] 接地：ODU、支架、网线屏蔽层按规范接地。
- [ ] 网线长度与线径满足 PoE 压降。
- [ ] 标签：端口、线缆、设备序列号。
- [ ] 现场拍照留档（朝向、走线、接地）。

## 5. 环境与可靠性

| 项 | 关注 |
|---|---|
| 防护 | IP65/IP67、防尘防水 |
| 温度 | 工作/存储范围、太阳暴晒温升 |
| 湿度/凝露 | 呼吸阀/密封 |
| 盐雾 | 沿海 |
| 风载 | 台风地区 |
| 雷击 | 直击/感应雷，接地与 SPD |
| 老化 | 高温满载、反复上下电 |

## 6. 软件与运维

| 能力 | 要求 |
|---|---|
| 远程升级 | 断点续传、失败回滚、A/B |
| 失联恢复 | 看门狗、定时重拨、自动重启 |
| 日志回传 | 本地环形缓冲 + 远程 syslog/TR-069 |
| 远程诊断 | 信号、温度、电压、流量、邻居小区 |
| 锁频/锁小区 | 防止飘站，需可配置 |
| 时间同步 | NTP/运营商时间 |
| 安全 | 关闭调试口、签名固件、最小服务 |

## 7. 验收指标（示例，需按项目替换）

| 指标 | 建议门槛 |
|---|---|
| RSRP | 按运营商要求（如 ≥ -100 dBm） |
| SINR | 按业务要求（如 ≥ 10 dB） |
| 下行/上行吞吐 | 达到套餐/合同的一定比例 |
| 时延/丢包 | 空闲/满载分别测 |
| 连续运行 | 72 h 无掉线/重启 |
| 上下电 | 50 次正常 |
| 高温满载 | 8 h 无降速/重启 |

## 8. 故障树

```text
ODU 不上电
├─ PoE 不供电 → PSE/线缆/分级
├─ 供电但反复重启 → 峰值电流/线损/浪涌
└─ 上电但无网 → 网线/IDU 端口/VLAN

信号差
├─ 朝向/遮挡 → 重新对准
├─ 频段/带宽 → 锁频/锁小区
├─ 干扰 → 扫频/换频
└─ 天线/馈线 → 驻波/接头

能上网但慢
├─ 信号 → RSRP/SINR
├─ 拥塞 → 时段/小区
├─ 模组 → 温度/降频
└─ 路由/NAT → 数据面
```
