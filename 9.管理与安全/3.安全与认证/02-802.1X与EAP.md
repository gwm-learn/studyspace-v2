# 802.1X 与 EAP

> 解决什么问题：有线/无线接入认证、动态 VLAN、认证失败定位。
> 不解决：具体 RADIUS 服务器产品配置。

## 1. 三角色

```text
Supplicant（终端）
   │ EAPOL（二层）
Authenticator（交换机/AP）
   │ RADIUS（UDP 1812/1813）
Authentication Server（RADIUS）
```

- 认证前：端口只放行 EAPOL。
- 认证后：端口授权/动态 VLAN/ACL。

## 2. 流程

```text
1. 端口未授权
2. Authenticator 发 EAP-Request/Identity
3. Supplicant 回 EAP-Response/Identity
4. Authenticator 封装 RADIUS Access-Request
5. 多轮 EAP 方法交互
6. Access-Accept/Reject
7. 授权端口/动态 VLAN
```

## 3. EAP 方法

| 方法 | 认证 | 特点 |
|---|---|---|
| EAP-TLS | 双向证书 | 最安全，部署证书 |
| PEAP | 服务器证书 + 用户名口令 | 常见 |
| EAP-TTLS | 服务器证书 + 隧道 | 灵活 |
| EAP-SIM/AKA | SIM | 蜂窝凭证 |
| MAB | MAC 地址 | 弱，兼容老设备 |

## 4. 动态 VLAN/ACL

RADIUS 返回：

```text
Tunnel-Type = VLAN
Tunnel-Medium-Type = IEEE-802
Tunnel-Private-Group-Id = 20
```

交换机把端口放入 VLAN 20；也可下发 ACL/带宽。

## 5. 配置要点（示意）

```text
# hostapd
ieee8021x=1
auth_server_addr=192.0.2.10
auth_server_port=1812
auth_server_shared_secret=...
dynamic_vlan=1
vlan_file=/etc/hostapd/vlan.conf
```

> 具体语法随 hostapd/交换机；先确认版本。

## 6. 排查

```bash
# Authenticator
logread | grep -i eap
hostapd_cli status
hostapd_cli all_sta

# RADIUS
radiusd -X
```

| 现象 | 首查 |
|---|---|
| 一直认证中 | 证书/时间/域名 |
| 认证成功无网 | 动态 VLAN/ACL |
| 无线失败 | PMF/加密/驱动 |
| 频繁重认证 | 会话超时/漫游 |
| MAB 不生效 | MAC 格式/白名单 |

## 7. 安全注意

- EAP-TLS/PEAP 必须校验证书，防中间人。
- 禁用弱方法（LEAP/MD5）。
- RADIUS 共享密钥强口令。
- 动态 VLAN 防越权。
- 日志脱敏。

## 8. 与 CPE 的关系

- 企业 AP/网关可做 Authenticator。
- CPE 作为 Supplicant 接入运营商/企业网络。
- 家庭场景较少用 802.1X，企业/园区常见。
