# 并发与同步

> 解决什么问题：偶发卡死、数据错乱、CPU 飙高、死锁、竞态；以及“到底该用线程/进程/协程”。
> 不解决：内核锁实现（见 [并发与锁调试](../../6.系统软件/1.Linux内核与驱动/10-并发与锁调试.md)）。

## 1. 执行模型

| 模型 | 地址空间 | 切换成本 | 适用 |
|---|---|---|---|
| 进程 | 独立 | 高 | 隔离/崩溃恢复 |
| 线程 | 共享 | 中 | 共享数据/并行 |
| 协程 | 共享 | 低 | IO 密集/高并发 |
| 事件循环 | 共享 | 最低 | 单线程非阻塞 |
| 中断/软中断 | 内核 | — | 不能睡眠 |

选择原则：**能不用共享就不用共享**；用消息传递/管道替代共享内存。

## 2. 内存模型与可见性

- 编译器/CPU 会重排；需要内存屏障/原子操作。
- C11/C++11：`memory_order_relaxed/acquire/release/seq_cst`。
- `volatile` 不是同步原语，只阻止编译器优化。
- 数据竞争 = 两个线程并发访问同一位置，至少一个写，且无同步 → UB。

## 3. 同步原语

### 3.1 互斥锁

```c
pthread_mutex_lock(&m);
/* critical section */
pthread_mutex_unlock(&m);
```

- 临界区尽量短；不要在持锁时做 IO/睡眠。
- 锁粒度：粗锁简单但并发差；细锁复杂但易死锁。

### 3.2 自旋锁

- 忙等，适合极短临界区/内核中断上下文。
- 用户态自旋浪费 CPU；单核上无意义。

### 3.3 读写锁

- 读多写少；写者可能饥饿。
- 读锁可共享，写锁独占。

### 3.4 信号量

- 计数信号量用于资源池/生产者-消费者。
- 二值信号量可当互斥，但语义不同（无所有者）。

### 3.5 条件变量

```c
pthread_mutex_lock(&m);
while (!ready) pthread_cond_wait(&cv, &m);
/* ... */
pthread_mutex_unlock(&m);
```

- 必须用 `while` 防虚假唤醒。
- 修改条件时持锁，再 `signal/broadcast`。

### 3.6 原子操作

- `atomic_int`、CAS、fetch-add。
- 适合计数器/标志；复杂结构仍建议锁。
- ABA 问题需要版本号/ Hazard pointer。

### 3.7 RCU

- 读侧无锁，写侧延迟释放。
- 适合读多写少（路由表/配置）。
- 需要理解宽限期（grace period）。

## 4. 死锁

四个必要条件：

1. 互斥。
2. 持有并等待。
3. 不可抢占。
4. 循环等待。

破坏任一：

- 全局锁顺序。
- 一次性申请所有锁。
- 超时/`trylock` 回退。
- 避免嵌套锁。

## 5. 常见并发模式

| 模式 | 说明 |
|---|---|
| 生产者-消费者 | 队列 + 条件变量/信号量 |
| 线程池 | 固定线程 + 任务队列 |
| Future/Promise | 异步结果 |
| Actor | 消息传递，无共享 |
| 读写分离 | 读多写少 |
| 无锁队列 | CAS/环形缓冲 |

## 6. 排查工具

```bash
gdb -p <pid> -ex 'thread apply all bt' -ex detach
strace -f -p <pid>
valgrind --tool=helgrind ./prog
valgrind --tool=drd ./prog
perf top -p <pid>
```

| 现象 | 首查 |
|---|---|
| 卡死 | 线程栈/锁持有者 |
| 数据错乱 | 共享写/内存屏障 |
| CPU 高 | 自旋/忙等/锁竞争 |
| 偶发崩溃 | 悬垂指针/生命周期 |
| 性能不随核数扩展 | 锁竞争/伪共享 |

## 7. 伪共享

- 不同线程写同一缓存行 → 缓存行来回失效。
- 对策：填充/对齐（`alignas(64)`）、按线程分片。

## 8. 工程规则

1. 共享数据必须有明确所有者/锁。
2. 锁顺序文档化。
3. 临界区不做阻塞调用。
4. 优先消息传递/无共享。
5. 并发 bug 先加时间戳/线程 ID 日志。
6. 用 TSan/helgrind 跑测试。

## 9. 实验

1. 写一个生产者-消费者（有界队列），用 helgrind 检查。
2. 制造死锁（AB/BA），用 gdb 看线程栈。
3. 用 `perf` 观察锁竞争/伪共享。
4. 用原子操作实现无锁计数器，对比互斥锁。
