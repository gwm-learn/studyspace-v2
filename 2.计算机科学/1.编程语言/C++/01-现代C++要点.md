# 现代 C++ 要点

> 解决什么问题：资源泄漏、悬垂指针、拷贝开销、ABI/异常/RTTI 在嵌入式上的取舍。
> 不解决：模板元编程/语言律师细节。

## 1. RAII

资源获取即初始化：构造获取、析构释放。

```cpp
class File {
  FILE* f_;
public:
  explicit File(const char* p) : f_(fopen(p, "r")) {}
  ~File() { if (f_) fclose(f_); }
  File(const File&) = delete;
  File& operator=(const File&) = delete;
};
```

RAII 适用于：内存、文件、锁、socket、句柄、临时状态。

## 2. 智能指针

| 指针 | 所有权 | 场景 |
|---|---|---|
| `unique_ptr` | 独占 | 默认首选 |
| `shared_ptr` | 共享 | 多持有者（慎用） |
| `weak_ptr` | 观察 | 打破循环 |

- `make_unique/make_shared` 避免显式 new。
- `shared_ptr` 有引用计数开销；嵌入式热路径避免。
- 不要用 `shared_ptr` 管理数组（用 `unique_ptr<T[]>`/vector）。

## 3. 拷贝/移动

```cpp
class Buffer {
  char* p_; size_t n_;
public:
  Buffer(Buffer&& o) noexcept : p_(o.p_), n_(o.n_) { o.p_=nullptr; o.n_=0; }
  Buffer& operator=(Buffer&& o) noexcept { /* ... */ return *this; }
};
```

规则：

- 自定义析构/拷贝/移动时要成套（Rule of Five）。
- 移动构造标 `noexcept`，否则容器可能选择拷贝。
- 移动后对象处于“有效但未指定”状态。

## 4. STL

| 容器 | 特点 | 注意 |
|---|---|---|
| `vector` | 连续、缓存友好 | 扩容失效迭代器 |
| `deque` | 双端 | 非连续 |
| `list` | 插入删除 O(1) | 缓存差 |
| `map` | 有序 | O(log n) |
| `unordered_map` | 哈希 | 最坏 O(n) |
| `array` | 固定大小 | 栈上 |

算法：`sort/find/transform/accumulate`；优先用算法而不是手写循环。

## 5. 模板

- 泛型容器/算法；避免过度模板化导致编译爆炸。
- `constexpr`/`if constexpr` 做编译期分支。
- 概念（C++20）改善报错；老工具链可能不支持。

## 6. 异常与 RTTI

| 选项 | 适用 |
|---|---|
| 异常 | 主机/复杂应用 |
| 错误码 | 嵌入式/实时 |
| `std::expected` | C++23，替代错误码 |

嵌入式常关闭异常/RTTI：

```bash
-fno-exceptions -fno-rtti
```

代价：STL 部分功能受限；需要错误码/断言替代。

## 7. 并发

- `std::thread`、`mutex`、`condition_variable`、`atomic`。
- 内存序：默认 `seq_cst`，性能敏感再放宽。
- 避免共享可变状态；优先消息传递。
- 线程析构前必须 join/detach。

## 8. 内存与性能

- 避免热路径动态分配；用对象池/预分配。
- 传参：小对象值传递，大对象 `const&`。
- 返回值依赖 RVO/NRVO。
- 关注缓存局部性/伪共享。
- 用 `perf`/`valgrind` 验证，不靠猜。

## 9. 嵌入式约束

| 约束 | 做法 |
|---|---|
| 无异常 | 错误码/`expected` |
| 无 RTTI | 避免 `dynamic_cast` |
| 内存小 | 静态分配/池 |
| 启动快 | 避免全局构造 |
| ABI | 固定编译器/标准库 |
| 二进制大小 | 关闭未用组件/`-Os` |

## 10. 常见坑

| 坑 | 说明 |
|---|---|
| 悬垂引用 | 返回局部变量引用 |
| 循环引用 | `shared_ptr` 互指 |
| 切片 | 值传递多态对象 |
| 迭代器失效 | 边遍历边删 |
| 未初始化 | 内置类型不默认初始化 |
| 隐式转换 | 单参构造加 `explicit` |
| ODR 违规 | 头文件定义非 inline |

## 11. 检查表

- [ ] 资源用 RAII。
- [ ] 所有权清晰（unique/shared/raw）。
- [ ] 拷贝/移动成套。
- [ ] 容器/迭代器生命周期。
- [ ] 异常/RTTI 策略明确。
- [ ] 并发有同步/无数据竞争。
- [ ] 热路径无频繁分配。
