# 语言核心


## 大小端（Endianness）详解


### 一、大小端的核心概念

大小端本质上描述的是多字节数据（比如 16 位、32 位整数）在内存中字节的存储顺序：

- **大端（Big-endian）**：高位字节存放在内存的低地址处，低位字节存放在内存的高地址处（符合人类阅读数字的习惯）。
- **小端（Little-endian）**：低位字节存放在内存的低地址处，高位字节存放在内存的高地址处（目前绝大多数计算机架构如 x86、x86-64 都采用小端）。

#### 举个直观例子

假设我们有一个 32 位整数 `0x12345678`（十进制 305419896），它由 4 个字节组成：`0x12`（最高位）、`0x34`、`0x56`、`0x78`（最低位）。如果这个数存放在内存地址从 `0x00` 到 `0x03` 的位置，两种存储方式的对比：

| 内存地址 | 大端存储（Big-endian） | 小端存储（Little-endian） |
|----------|------------------------|---------------------------|
| 0x00 | 0x12（高位） | 0x78（低位） |
| 0x01 | 0x34 | 0x56 |
| 0x02 | 0x56 | 0x34 |
| 0x03 | 0x78（低位） | 0x12（高位） |

### 二、为什么要关注大小端？

大小端本身没有优劣，但在以下场景必须统一规则，否则会导致数据解析错误：

- **跨平台数据交互**：比如 x86（小端）的程序向 ARM（可配置大小端）的设备传输数据；
- **网络通信**：网络协议（如 TCP/IP）规定使用大端序（也叫 “网络字节序”），所有数据传输前必须转换；
- **文件解析**：比如解析图片、视频、二进制文件时，文件格式会明确指定字节序。

### 三、代码示例：检测当前系统的字节序

下面用 C 语言示例检测系统是大端还是小端，原理是利用 “共用体（union）的所有成员共享同一块内存”：

```c
#include <stdio.h>

// 检测字节序的函数
int check_endianness() {
    // 共用体：int 占 4 字节，char 占 1 字节，共享首地址
    union {
        int num;       // 4 字节整数：0x00000001
        char byte;     // 取首地址的 1 字节
    } endian_test;

    endian_test.num = 1;  // 赋值为 1，二进制：00000000 00000000 00000000 00000001
    
    // 如果首地址的字节是 1 → 小端（低位存低地址）；如果是 0 → 大端
    return (endian_test.byte == 1) ? 1 : 0;
}

int main() {
    if (check_endianness()) {
        printf("当前系统是小端序（Little-endian）\n");
    } else {
        printf("当前系统是大端序（Big-endian）\n");
    }
    return 0;
}
```

**运行结果**：

- x86/x86-64 架构（如 Windows、Linux 桌面版）：输出 “当前系统是小端序”；
- 部分嵌入式 ARM 系统（配置为大端）：输出 “当前系统是大端序”。

### 四、网络字节序转换（以 C 语言为例）

操作系统提供了标准函数，用于将主机字节序和网络字节序互转：

```c
#include <arpa/inet.h>

// 16 位整数转换：主机序 → 网络序（大端）
uint16_t htons(uint16_t hostshort);
// 16 位整数转换：网络序 → 主机序
uint16_t ntohs(uint16_t netshort);

// 32 位整数转换：主机序 → 网络序
uint32_t htonl(uint32_t hostlong);
// 32 位整数转换：网络序 → 主机序
uint32_t ntohl(uint32_t netlong);
```

- `h` = host（主机），`n` = network（网络），`s` = short（16 位），`l` = long（32 位）；
- 无论主机是大端还是小端，调用这些函数后都会统一为网络字节序（大端）。

### 总结

1. **大端**：高位字节存低地址（符合人类阅读习惯），**小端**：低位字节存低地址（主流硬件架构采用）；
2. 大小端问题仅针对多字节数据，单字节数据无字节序问题；
3. 跨平台 / 网络传输时，必须统一字节序（通常用大端），否则会导致数据解析错误。

## 链表申请空间


```C
typedef int (*comm_list_foreach_callback)(void *listnode, void *outputdata);

typedef struct _COMM_LIST_HEAD {
	struct _COMM_LIST_HEAD *next;
	unsigned char data[0];
}COMM_LIST_HEAD;

//申请新元素并将新元素插入为链表新头
void *malloc_in_comm_list(void **listhead, int size)
{
	if (listhead && size > sizeof(void *))
	{
		COMM_LIST_HEAD *pCurr = (COMM_LIST_HEAD *)malloc(size);
		if (pCurr)
		{
			memset(pCurr, 0x0, size);
			if (*listhead)
			{
				pCurr->next = (COMM_LIST_HEAD *)(*listhead);
				*listhead = pCurr;
			}
			else
			{
				*listhead = pCurr;
			}
		}
		return pCurr;
	}
	return NULL;
}

//链尾申请新元素
void *malloc_in_comm_list_tail(void **listhead, int size)
{
	if (listhead && size > sizeof(void *))
	{
		COMM_LIST_HEAD *pCurr = (COMM_LIST_HEAD *)malloc(size);
		if (pCurr)
		{
			memset(pCurr, 0x0, size);
			if (*listhead)
			{
				COMM_LIST_HEAD *pTail = (COMM_LIST_HEAD *)(*listhead);
				while(pTail->next) pTail = pTail->next;
				pTail->next = pCurr;
			}
			else
			{
				*listhead = pCurr;
			}
		}
		return pCurr;
	}
	return NULL;
}

//释放所有链元素
void free_whole_comm_list(void **listhead)
{
	if (listhead && *listhead)
	{
		COMM_LIST_HEAD *pCurr = ((COMM_LIST_HEAD *)(*listhead));
		COMM_LIST_HEAD *pNext = pCurr->next;
		*listhead = NULL;
		while(pCurr)
		{
			free(pCurr);
			pCurr = pNext;
			if (pNext) { pNext = pNext->next; }
		}
	}
}

//链表中释放某一元素listNode
void free_in_comm_list(void **listhead, void *listNode) {
	if (listhead && *listhead && listNode)
	{
		COMM_LIST_HEAD *pPre = ((COMM_LIST_HEAD *)(*listhead));
		COMM_LIST_HEAD *pTmp = pPre->next;

		if (*listhead == listNode)
		{
			*listhead = pTmp;
			free(listNode);
		}
		else
		{
			while(pTmp)
			{
				if (pTmp == listNode)
				{
					pPre->next = pTmp->next;
					free(listNode);
					break;
				}
				pPre = pTmp;
				pTmp = pTmp->next;
			}
		}
	}
}

//取元素数据到outputdata，foreach_callback需要自己额外根据实际情况实现
int foreach_in_comm_list(void **listhead, comm_list_foreach_callback foreach_callback, void *outputdata)
{
	int count = 0;
	
	if (listhead && *listhead)
	{
		COMM_LIST_HEAD *pCurr = ((COMM_LIST_HEAD *)(*listhead));
		while(pCurr)
		{
			if (foreach_callback(pCurr, outputdata) != 0)
			{
				break;
			}
			else
			{
				count++;
			}
			pCurr = pCurr->next;
		}
	}
	return count;
}
```
