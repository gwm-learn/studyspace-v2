# 算法设计

> 解决什么问题：判断一个实现能否在“10 万条表项 / 百万 PPS / 低内存”下存活；以及如何把慢路径改成可预测的快路径。
> 不解决：具体数据结构实现（见 [数据结构复习提纲](01-数据结构复习提纲.md)）。

## 1. 复杂度

| 记号 | 名称 | 典型 |
|---|---|---|
| O(1) | 常数 | 数组索引、哈希 |
| O(log n) | 对数 | 二分、平衡树 |
| O(n) | 线性 | 遍历、计数 |
| O(n log n) | 线性对数 | 排序、堆 |
| O(n²) | 平方 | 双重循环 |
| O(2^n) | 指数 | 暴力子集 |

工程上还要看：

- 最坏/平均/摊还复杂度。
- 常数因子（缓存/分支/内存访问）。
- 空间复杂度与分配次数。
- 可预测性（实时路径避免深递归/动态分配）。

## 2. 递归与分治

```text
divide → conquer → combine
```

| 问题 | 分治思路 | 复杂度 |
|---|---|---|
| 归并排序 | 二分 + 合并 | O(n log n) |
| 快速排序 | 分区 + 递归 | 平均 O(n log n)，最坏 O(n²) |
| 二分查找 | 折半 | O(log n) |
| 快速选择 | 分区 | 平均 O(n) |

注意：递归深度受栈限制；嵌入式优先迭代/尾递归。

## 3. 动态规划

适用条件：

1. 最优子结构。
2. 重叠子问题。

步骤：

1. 定义状态 `dp[i]`。
2. 写转移方程。
3. 确定初始/边界。
4. 确定遍历顺序。
5. 优化空间（滚动数组）。

例子：最长公共子序列

```text
dp[i][j] = dp[i-1][j-1] + 1                     if a[i]==b[j]
         = max(dp[i-1][j], dp[i][j-1])          otherwise
```

工程例子：路由表前缀匹配可用 Trie/DP；QoS 令牌桶是状态机而非 DP。

## 4. 贪心

- 每步取局部最优，需证明全局最优。
- 典型：最小生成树、Dijkstra（非负权）、区间调度、Huffman。
- 反例：0/1 背包不能用贪心（按价值/重量比会错）。

## 5. 图算法

| 算法 | 用途 | 复杂度 |
|---|---|---|
| BFS | 无权最短路/分层 | O(V+E) |
| DFS | 连通/环/拓扑 | O(V+E) |
| Dijkstra | 非负权最短路 | O((V+E)logV) |
| Bellman-Ford | 负权/检测负环 | O(VE) |
| Floyd | 全源最短路 | O(V³) |
| Kruskal/Prim | 最小生成树 | O(ElogE)/O(ElogV) |
| Tarjan | 强连通/割点 | O(V+E) |

网络设备里：拓扑/邻居/环路检测常用 BFS/DFS/并查集；路由收敛更像分布式 Bellman-Ford/SPF。

## 6. 字符串与哈希

- 字符串匹配：KMP、Boyer-Moore、Rabin-Karp。
- 哈希：平均 O(1)，最坏 O(n)；要防碰撞攻击。
- 布隆过滤器：低内存判存在，有假阳性。
- 前缀树：路由/命令补全。

## 7. 嵌入式约束

| 约束 | 做法 |
|---|---|
| 内存小 | 静态分配/对象池 |
| 实时 | 避免 O(n²)/深递归/锁 |
| 缓存 | 顺序访问、少指针跳转 |
| 可预测 | 固定上限、失败快速返回 |
| 功耗 | 少唤醒/少拷贝 |

## 8. 性能分析

```bash
perf stat -e cycles,instructions,cache-misses ./prog
perf record -g ./prog && perf report
valgrind --tool=callgrind ./prog
```

关注：指令数、缓存命中、分支预测、内存分配、锁竞争。

## 9. 常见误区

| 误区 | 纠正 |
|---|---|
| 复杂度低一定快 | 常数/缓存/分支也重要 |
| 哈希永远 O(1) | 碰撞/扩容/攻击 |
| 递归更优雅 | 栈溢出/不可预测 |
| 优化靠猜 | 先用 profiler |
| 过早优化 | 先正确，再测量 |

## 10. 练习

1. 实现 LRU（哈希+双向链表）。
2. 实现 Trie，做 IP 前缀匹配。
3. 用 DP 解背包，对比贪心反例。
4. 用 perf 找一段代码的热点。
