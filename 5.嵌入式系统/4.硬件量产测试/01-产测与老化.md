# 产测与老化（硬件侧）

> 解决什么问题：批量一致性、早期失效、产线误判、追溯困难。
> 不解决：产线流程/MAC/SN/校准/MES（见 [生产与校准](../../11.应用与案例/4.生产与校准/01-产测与校准.md)）。

## 1. 测试分层

```text
单板测试（PCBA）
  → 整机测试
    → 校准
      → 老化
        → 终检/包装
```

| 层 | 目标 | 典型项 |
|---|---|---|
| 单板 | 焊接/器件 | 电源、时钟、DDR、Flash、网口 |
| 整机 | 功能 | 启动、Wi-Fi、USB、按键/LED |
| 校准 | 射频一致 | 功率、频偏、EVM、灵敏度 |
| 老化 | 早期失效 | 高温满载 4–24 h |
| 终检 | 出厂 | 外观/标签/配件/版本 |

## 2. 治具与自动化

- 治具要保证接触可靠/防呆/可重复。
- 测试脚本自动判定，减少人为主观。
- 失败记录现象/数据/照片。
- 治具定期校准/维护。

## 3. 测试项与阈值

| 项 | 方法 | 阈值（示例） |
|---|---|---|
| 输入电压 | 万用表 | 规格 ±5% |
| 待机/峰值电流 | 电流表 | 按设计 |
| 网口 | 回环/对测 | 千兆/百兆 |
| Wi-Fi | 扫描/吞吐 | 功率/速率 |
| USB | 枚举/读写 | 稳定 |
| 按键/LED | 自动触发 | 全通过 |
| 温度 | 传感器 | 不超阈值 |

> 阈值来自设计/校准/历史数据，不要拍脑袋。

## 4. 老化

| 项 | 建议 |
|---|---|
| 温度 | 55–70 °C（按产品） |
| 时间 | 4–24 h |
| 负载 | 满载/周期业务 |
| 监控 | 重启/掉线/温度/电流 |
| 抽样 | 批量抽检 + 关键全检 |

老化后复测关键指标，筛出早期失效。

## 5. 追溯

```text
SN ↔ MAC ↔ 校准 ↔ 测试记录 ↔ 批次 ↔ 出货
```

- 每台设备一条记录。
- 失败/返修记录可查。
- 固件/校准版本与认证版本一致。

## 6. 常见问题

| 现象 | 原因 |
|---|---|
| 批量 MAC 冲突 | 分配/写入脚本 |
| 校准丢失 | 分区/写入校验 |
| 老化后失效 | 早期失效/散热 |
| 误判高 | 阈值/治具/脚本 |
| 出货版本错 | 工单/固件包 |
| 批次差异 | 器件/工艺 |

## 7. 检查表

- [ ] 治具/脚本/阈值版本化。
- [ ] 每台 SN/MAC 唯一。
- [ ] 校准写入并回读。
- [ ] 老化监控/复测。
- [ ] 失败隔离/返修。
- [ ] 记录可追溯。
