# 高速接口 SI（板级）

> 解决什么问题：板级走线/叠层/连接器导致 USB3 枚举失败、PCIe 训练失败、千兆丢包、DDR 不稳。
> 不解决：芯片 PHY 内部均衡/调参（按厂商指南）。

## 1. 叠层与阻抗

| 项 | 目标 |
|---|---|
| 单端 | 50 Ω |
| 差分 | 90/100 Ω（USB/PCIe/以太网） |
| 参考平面 | 完整、连续 |
| 介质 | FR4/高速材料按损耗选 |

- 阻抗由线宽/间距/介质厚度/铜厚决定；用叠层工具算，不要凭经验。
- 高速层尽量夹在地平面之间；避免跨分割。
- 过孔 stub 对高速信号有影响；必要时背钻。

## 2. 布线规则

| 规则 | 说明 |
|---|---|
| 差分等长 | 对内偏斜按接口规范 |
| 差分等距 | 保持阻抗 |
| 少换层 | 换层加回流地孔 |
| 3W 间距 | 减少串扰 |
| 参考平面 | 不跨分割 |
| 连接器 | 阻抗连续、地针充分 |

## 3. 接口要点

### 3.1 USB3

- TX/RX 差分对，90 Ω；AC 耦合电容按规范。
- VBUS 压降/瞬态；ESD 靠近接口。
- 2.4G 干扰：扩频/屏蔽/远离天线。

### 3.2 PCIe

- REFCLK 100 MHz 差分；PERST# 时序。
- lane 极性可反转；AC 耦合靠近发送端。
- 链路训练失败先查时钟/供电/复位。

### 3.3 千兆以太网

- 变压器隔离、中心抽头、MDI 100 Ω。
- 四对差分；PoE 与数据共用变压器。
- 丢包查线缆/变压器/PHY/驱动。

### 3.4 DDR

- 地址/命令/数据等长/飞行时间；VREF/电源纹波。
- 拓扑（fly-by/T 型）按 SoC 指南。
- 训练失败查颗粒/电源/温度/走线。

## 4. 去耦与电源

- 大电容 + 小电容，靠近引脚。
- 开关电源环路小，远离高速线。
- DDR VREF/电源纹波直接影响训练。
- 射频电源用 LDO/滤波。

## 5. 测量

| 工具 | 用途 |
|---|---|
| 示波器（高带宽） | 眼图/过冲/抖动 |
| TDR | 阻抗/断点 |
| VNA | S 参数/回波 |
| 协议分析仪 | 链路训练/枚举 |
| 热像仪 | 异常发热 |

## 6. 调试顺序

1. 电源/地/时钟。
2. 阻抗/端接/AC 耦合。
3. 眼图/抖动/串扰。
4. 固件均衡/预加重。
5. 连接器/线缆替换验证。

## 7. 常见故障

| 现象 | 首查 |
|---|---|
| USB3 只跑 USB2 | SS 对/阻抗/连接器 |
| PCIe 不识别 | REFCLK/PERST/供电 |
| 千兆降百兆 | 线缆/变压器/PHY |
| DDR 偶发错误 | 电源/时序/温度 |
| 辐射超标 | 共模/回流/时钟 |
| 插拔后异常 | ESD/连接器/地 |
