# EMC 与 ESD（板级）

> 解决什么问题：认证辐射超标、ESD 打接口复位、雷击损坏、Wi-Fi 底噪高。
> 不解决：具体认证流程（见 [认证与入库](../../11.应用与案例/3.测试与认证/01-认证与入库.md)）。

## 1. 三类测试

| 类型 | 测试 | 常见现象 |
|---|---|---|
| 辐射发射 | 天线/接收机 | 超标、干扰接收 |
| 传导发射 | LISN | 电源线超标 |
| 抗扰 | ESD/EFT/浪涌 | 复位/死机/损坏 |

## 2. 板级设计

### 2.1 电源

- 输入滤波：共模电感、X/Y 电容、TVS。
- 开关电源环路小；输入电容靠近开关管。
- 分区：模拟/数字/射频；避免噪声串扰。

### 2.2 高速线

- 参考平面完整，少跨分割。
- 差分共模抑制；必要时共模扼流圈。
- 时钟远离板边/接口；包地。

### 2.3 接口

| 接口 | 保护 |
|---|---|
| USB | ESD 阵列、VBUS 限流 |
| 以太网 | 变压器、共模扼流、TVS |
| PoE | TVS/压敏/GDT、保险丝 |
| 天线 | 接地/防雷 |
| 按键/LED | RC/ESD |

### 2.4 接地/屏蔽

- 机壳地/信号地/保护地区分。
- 连接器屏蔽层 360° 接地。
- 屏蔽罩多点搭接；导电泡棉压缩。
- 线缆屏蔽层与机壳低阻连接。

## 3. ESD

放电路径：

```text
接口 → TVS → 地 → 机壳 → 大地
```

常见错误：

- TVS 离接口太远（走线电感）。
- 地回路长/地弹。
- 信号线无保护。
- 复位线/电源无滤波。

## 4. 浪涌/雷击

- 室外口必须做多级保护：GDT/压敏 + TVS + PPTC。
- 接地/等电位是基础。
- 保护器件要配合（电压/电流/响应时间）。
- 雷击损坏常查接地，不是只换 TVS。

## 5. 预测试

| 工具 | 用途 |
|---|---|
| 近场探头 + 频谱仪 | 找辐射源 |
| 电流探头 | 共模电流 |
| 静电枪 | ESD |
| 浪涌/EFT 发生器 | 抗扰 |
| 热像仪 | 异常发热 |

定位：拔模块/断线二分 → 近场扫描 → 改源/路径 → 复测。

## 6. 常见故障

| 现象 | 原因 |
|---|---|
| 30–100 MHz 辐射 | 电源/时钟 |
| 2.4G 底噪 | USB3/DC-DC/屏线 |
| ESD 复位 | TVS/地/复位 |
| 网口雷击 | 无浪涌/接地 |
| 辐射随线缆变 | 共模电流 |
| 认证边缘 | 余量不足/批次差异 |
