# 接口与外设

> 解决什么问题：路由器板子上除网口/Wi-Fi 之外的常见外设怎么接、怎么验。
> 不解决：具体驱动的源码逐行分析（见 [驱动模型](../../6.%E7%B3%BB%E7%BB%9F%E8%BD%AF%E4%BB%B6/1.Linux%E5%86%85%E6%A0%B8%E4%B8%8E%E9%A9%B1%E5%8A%A8/04-%E9%A9%B1%E5%8A%A8%E6%A8%A1%E5%9E%8B.md)）。

## 1. GPIO / LED / 按键

### 1.1 链路

```text
DTS: gpio-leds / gpio-keys
        │
        ▼
内核: leds-gpio / gpio-keys 驱动
        │
        ▼
用户态: /sys/class/leds/*、input 事件、procd hotplug
```

### 1.2 常用命令

```bash
# LED
ls /sys/class/leds/
cat /sys/class/leds/*/trigger
echo heartbeat > /sys/class/leds/status/trigger

# GPIO
gpioinfo
gpioget gpiochip0 12
gpioset gpiochip0 12=1
cat /sys/kernel/debug/gpio

# 按键
evtest
hexdump /dev/input/event0
```

### 1.3 按键到恢复出厂

```text
按键按下 → 内核 input 事件 → procd hotplug → /etc/rc.button/reset
        → 长按计时 → firstboot / reboot
```

排查要点：DTS 的 `linux,code`、`GPIO_ACTIVE_LOW`、`/etc/rc.button/` 脚本、长按阈值。

## 2. UART

| 项 | 说明 |
|---|---|
| 用途 | 启动日志、U-Boot 控制台、救援 |
| 参数 | 常见 115200 8N1，3.3V TTL |
| 接线 | TX↔RX、RX↔TX、GND↔GND；不要接 VCC |
| 风险 | 电平不匹配会烧 SoC；先量电压 |

```bash
# Linux 侧
picocom -b 115200 /dev/ttyUSB0
screen /dev/ttyUSB0 115200
```

## 3. USB

| 场景 | 说明 |
|---|---|
| USB 存储 | 日志、配置备份、升级包 |
| USB 蜂窝模组 | QMI/MBIM/AT，供电与枚举是关键 |
| USB 转串口 | 调试 |
| USB 供电 | 注意限流与压降，模组峰值电流可能 >2A |

```bash
lsusb -t
dmesg | grep -i usb
cat /sys/bus/usb/devices/*/idVendor
```

常见问题：供电不足导致反复枚举；`option`/`qmi_wwan`/`cdc_mbim` 驱动未绑定；USB 3.0 干扰 2.4G Wi-Fi。

## 4. PCIe

| 场景 | 说明 |
|---|---|
| Wi-Fi 模组 | MT76 常见 PCIe |
| 以太网/交换 | 部分方案 |
| 5G 模组 | M.2/PCIe |

```bash
lspci -nn
lspci -vvv
dmesg | grep -i pcie
```

常见问题：PERST/时钟/供电时序、lane 反转、BIOS/ATF 初始化、ASPM 兼容性。

## 5. I2C / SPI

| 总线 | 典型设备 | 工具 |
|---|---|---|
| I2C | EEPROM、温度传感器、PHY、LED 控制器 | `i2cdetect -y 0`、`i2cget/i2cset` |
| SPI | NOR/NAND Flash、部分 Wi-Fi | `spi-config`、`flashrom`（谨慎） |

> 总线上的地址与片选必须查原理图；误操作可能改写校准数据。

## 6. 电源、风扇、温度

| 项 | 检查 |
|---|---|
| 输入电压 | 空载/满载/峰值 |
| PoE | 802.3af/at/bt、握手、分级、浪涌 |
| 温度 | `thermal_zone`、风扇曲线、降频策略 |
| 功耗 | 待机/满载/峰值，与电源余量匹配 |

```bash
cat /sys/class/thermal/thermal_zone*/temp
cat /sys/class/hwmon/hwmon*/temp1_input
```

## 7. 最小验证清单

- [ ] LED 可控、trigger 正确、重启后状态符合预期。
- [ ] 按键事件可读，长按能触发恢复出厂。
- [ ] 串口能完整抓到 U-Boot + kernel 日志。
- [ ] USB 模组枚举稳定，断电重启 20 次无掉枚举。
- [ ] PCIe 设备在冷启动/热重启下都能识别。
- [ ] 温度/功耗在满载 1 小时后不超阈值。
