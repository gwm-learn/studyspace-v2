# 硬件调试与测量

> 解决什么问题：板子不启动、不稳定、发热、功耗异常时，怎么从硬件侧定位。
> 前置：安全第一。涉及强电/高温/高速信号时，必须有防护与第二人。

## 1. 工具清单

| 工具 | 用途 | 备注 |
|---|---|---|
| 万用表 | 电压、通断、电阻 | 最常用 |
| 直流电源（可调限流） | 供电、看电流 | 必带限流 |
| USB 电流表 | 模组/整机功耗 | 注意量程 |
| 示波器 | 纹波、时序、时钟、差分 | ≥100 MHz 带宽 |
| 逻辑分析仪 | I2C/SPI/UART | 抓协议 |
| 热像仪 | 发热定位 | 安全、快速 |
| 串口板 | 启动日志 | 3.3V TTL |
| JTAG | 救砖/裸机调试 | 最后手段 |
| 假负载/电子负载 | 电源测试 | — |

## 2. 上电前的检查

- [ ] 目视：短路、虚焊、极性、连锡、器件方向。
- [ ] 通断：电源对地电阻（不应接近 0）。
- [ ] 电压档位：输入电压与板子标称一致。
- [ ] 限流：先设小电流（如 0.5 A），看是否异常。
- [ ] 串口：TX/RX 交叉、GND 共地、电平匹配。

## 3. 启动日志抓取

```bash
# Linux/macOS
picocom -b 115200 /dev/ttyUSB0
# 或
screen /dev/ttyUSB0 115200
```

记录要点：

| 阶段 | 关键日志 |
|---|---|
| BootROM | 芯片型号、启动介质 |
| BL2 | DRAM 初始化、频率 |
| U-Boot | 版本、环境变量、加载地址 |
| kernel | `Booting Linux`、`Memory:`、`console` |
| 驱动 | `probe` 成功/失败、`-EPROBE_DEFER` |
| rootfs | `VFS: Mounted root`、`init` |
| 用户态 | procd、网络接口、服务启动 |

> 日志要整段保存，不要只截最后一行。

## 4. 电源与功耗

| 测量 | 方法 | 判据 |
|---|---|---|
| 空载电压 | 万用表 | 在规格 ±5% 内 |
| 满载电压 | 电子负载/整机满载 | 不低于最低工作电压 |
| 纹波 | 示波器 AC 耦合、20 MHz 带宽限制 | 通常 <50 mVpp（按器件要求） |
| 峰值电流 | 电流探头/电流表 | 不超过电源与线缆能力 |
| 温升 | 热像仪/热电偶 | 关键器件结温留余量 |

常见问题：Wi-Fi/蜂窝发射瞬间电流突增导致复位；USB 线压降；PoE 分级不匹配。

## 5. 信号与时序

| 场景 | 看什么 |
|---|---|
| DDR 不稳定 | 时钟、VREF、电源纹波、PCB 走线 |
| PCIe 不识别 | PERST、REFCLK、供电、lane 极性 |
| USB 枚举失败 | D+/D- 眼图、VBUS、ESD |
| I2C 不通 | 上拉、地址、时钟拉伸 |
| SPI Flash 读写错 | CS/CLK/MOSI/MISO、模式、速率 |
| 复位异常 | RESET 毛刺、看门狗、电源跌落 |

## 6. 热与结构

- 满载 1 小时，记录 SoC/PA/电源/模组温度。
- 高温降频策略是否生效（`thermal_zone`）。
- 风扇曲线、风道、导热垫是否到位。
- ODU 还要看太阳暴晒、密封、凝露。

## 7. 常见故障树

```text
不上电
├─ 无输入电压 → 电源/线缆/POE
├─ 输入短路 → 器件击穿/焊接
├─ 有电压无电流 → 电源使能/时序
└─ 电流过大 → 短路/器件损坏

不启动
├─ 无串口输出 → 供电/晶振/复位/串口
├─ 卡 BL2 → DDR/时钟/介质
├─ 卡 U-Boot → 环境变量/镜像/网络
└─ 卡内核 → bootargs/DTB/rootfs
```

## 8. 安全与规范

- 断电再改线；电容放电后再操作。
- 示波器探头接地要可靠，避免短路。
- 热风枪/烙铁注意通风与防静电。
- 不得在带电情况下插拔模组（除非明确支持热插拔）。
- 高压/大电流测试必须有人监护。
