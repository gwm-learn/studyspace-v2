# 热设计与降频

> 解决什么问题：满载/高温/密闭外壳下掉速、重启、寿命下降；以及怎么判断是热问题。
> 不解决：具体散热器选型/仿真（按项目）。

## 1. 热阻模型

```text
Tj = Ta + P × (Rth_jc + Rth_ca)
```

- `Tj`：结温。
- `Ta`：环境温度。
- `P`：功耗。
- `Rth_jc`：结到壳。
- `Rth_ca`：壳到环境（散热器/外壳/风道）。

串联热阻：界面材料、散热器、外壳、空气。

## 2. 设计要素

| 要素 | 要点 |
|---|---|
| 导热垫 | 厚度/压缩量/导热系数；贴合比“厚”重要 |
| 散热器 | 面积/鳍片/风道；自然对流 vs 强制风冷 |
| 外壳 | 金属/塑料、开孔、导热路径 |
| 风扇 | 曲线/噪声/寿命/防尘 |
| 布局 | 发热源分散，远离温度敏感器件 |
| 降频 | 温度阈值/策略/滞回 |

## 3. 计算示例

`P=5 W`、`Rth_jc=2 °C/W`、`Rth_ca=8 °C/W`、`Ta=40 °C`：

```text
Tj = 40 + 5 × (2+8) = 90 °C
```

若结温上限 105 °C，余量 15 °C；高温/密闭可能不够。

## 4. 降频策略

- 温度阈值分级（如 85/95/105 °C）。
- 降频/降功率/关射频/降亮度。
- 滞回避免频繁切换。
- 记录降频事件，便于现场分析。

```bash
cat /sys/class/thermal/thermal_zone*/temp
cat /sys/class/thermal/thermal_zone*/trip_point_*_temp
cat /sys/class/hwmon/hwmon*/temp1_input
```

## 5. 验证

| 项 | 方法 | 判据 |
|---|---|---|
| 满载温升 | 满载 1 h | 关键器件留余量 |
| 高温环境 | 烘箱/密闭 | 不降速/不死机 |
| 反复上下电 | 50 次 | 正常 |
| 风扇故障 | 堵转 | 不烧/可降频 |
| 长期 | 24–72 h | 无漂移 |

## 6. 常见问题

| 现象 | 原因 |
|---|---|
| 短时正常、长时掉速 | 热积累 |
| 夏天现场重启 | 余量不足 |
| 局部过热 | 导热垫未贴合/风道短路 |
| 风扇噪声大 | 曲线激进/轴承 |
| 温度读数异常 | 传感器位置/校准 |

## 7. 设计建议

- 热设计从功耗预算开始，不要最后补散热。
- 关键器件留 15–20 °C 余量。
- 导热界面材料要按压缩量设计。
- 外壳开孔要有风道，避免“开了但没风”。
- 降频策略要可观测/可配置。
