# 资料索引：{{分类}}

> 每份资料都要有"消化状态"，否则视为未收录。

| 文件 | 来源/编号 | 版本 | 大小 | 对应笔记 | 消化状态 |
|---|---|---|---:|---|---|
|  |  |  |  |  | 未读 / 已索引 / 已精读 |

## 消化状态定义

| 状态 | 含义 |
|---|---|
| 未读 | 只归档，未看 |
| 已索引 | 知道大概内容，笔记中引用了 |
| 已精读 | 有对应笔记，关键结论有摘录与核对 |
