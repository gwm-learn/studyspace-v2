# 框架说明

本目录只放“怎么理解和查找知识”的东西，不放技术正文。

> **定位**：这是一个**知识框架**，不是课程表，也不是项目计划。
> 组织轴是学科/知识域，不是 OpenWrt，也不是项目周期。

## 三种查法

### 1. 按概念查

从 [知识框架.md](知识框架.md) 的域表进入 → 子域 Hub → 具体笔记。

### 2. 按实现链查

从 [知识框架图.md](知识框架图.md) 的“一个包的一生 / 一次入网 / 一次升级”三条主线进入。

### 3. 按问题查

从 [知识框架.md](知识框架.md) 的“定位决策树”选择域；现场问题先到 [应用与案例/5.运维与故障案例](../11.应用与案例/5.运维与故障案例/00-总览.md)。

## 维护规则

- 新增内容必须归入 11 个知识域之一；平台细节归 `7.平台与集成`，项目内容归 `11.应用与案例`。
- 知识域页面只做边界与索引，不复制技术正文。
- 新增/移动文件后重跑 `tools/gen_framework_map.py` 与 `tools/kb_lint.py`。
