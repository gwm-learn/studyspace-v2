# 术语与缩略语

> 只收录本库跨域出现的词。某个主题内部的细节术语，放在该主题 Hub 的"术语"小节。

## 网络基础

| 缩写/术语 | 全称 | 一句话解释 |
|---|---|---|
| MAC | Media Access Control | 链路层地址，以太网为 48 位 |
| MTU | Maximum Transmission Unit | 一次可传输的最大载荷，以太网通常 1500 |
| PMTU | Path MTU | 路径上最小 MTU，靠 ICMP 差错或 PLPMTUD 发现 |
| ARP | Address Resolution Protocol | IPv4 地址 → MAC |
| NDP | Neighbor Discovery Protocol | IPv6 的邻居发现（NS/NA/RS/RA） |
| RA | Router Advertisement | IPv6 路由器通告，携带前缀/网关/DNS |
| SLAAC | Stateless Address Autoconfiguration | IPv6 无状态地址自动配置 |
| DHCPv6 | DHCP for IPv6 | IPv6 有状态地址/前缀分配 |
| PD | Prefix Delegation | 运营商向 CPE 委派 IPv6 前缀 |
| NAT | Network Address Translation | 地址转换 |
| SNAT/DNAT | Source/Destination NAT | 源/目的地址转换 |
| ALG | Application Layer Gateway | 应用层网关，处理 SIP/FTP 等嵌入地址 |
| conntrack | Connection Tracking | 内核连接跟踪表 |
| DSA | Distributed Switch Architecture | 内核交换机框架，每端口一个 netdev |
| swconfig | Switch Configuration | OpenWrt 旧交换机配置框架 |
| VLAN | Virtual LAN | 二层逻辑隔离 |
| PVID | Port VLAN ID | 端口默认 VLAN |
| STP/RSTP/MSTP | Spanning Tree Protocol | 防环 |
| LACP | Link Aggregation Control Protocol | 链路聚合协商 |
| VRRP | Virtual Router Redundancy Protocol | 网关冗余 |
| IGMP | Internet Group Management Protocol | IPv4 组播成员管理 |
| MLD | Multicast Listener Discovery | IPv6 组播成员管理 |
| QoS | Quality of Service | 服务质量 |
| DSCP | Differentiated Services Code Point | IP 头中的优先级字段 |
| TC | Traffic Control | Linux 流量控制子系统 |
| HTB | Hierarchical Token Bucket | 分层令牌桶队列 |
| CAKE | Common Applications Kept Enhanced | 现代排队算法 |
| SQM | Smart Queue Management | OpenWrt 智能队列（抗 bufferbloat） |
| offload | Hardware/Flow Offload | 转发卸载到硬件/流表 |
