# 知识框架图

> 这张图把**知识域、概念、实现、应用**串起来；它不是课程表，也不是项目排期。
> 先看域间关系，再按“包的一生 / 一次入网 / 一次升级”三条主线跳转。

## 1. 域间关系

```mermaid
flowchart TD
  FND["1.基础科学"] --> COM["4.通信科学"]
  FND --> EMB["5.嵌入式系统"]
  FND --> NET["3.网络科学"]
  CS["2.计算机科学"] --> OS["6.系统软件"]
  CS --> NET
  NET --> DP["8.数据面工程"]
  OS --> DP
  EMB --> OS
  COM --> NET
  PLT["7.平台与集成"] --> DP
  OS --> PLT
  DP --> SEC["9.管理与安全"]
  NET --> SEC
  ENG["10.工程方法"] -.-> NET
  ENG -.-> OS
  ENG -.-> DP
  APP["11.应用与案例"] -.-> PLT
  APP -.-> SEC
```

> 实线：概念/实现依赖；虚线：方法/验证反哺。
