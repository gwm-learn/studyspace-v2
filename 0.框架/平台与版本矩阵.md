# 平台与版本矩阵

> 作用：任何实现类笔记都必须能回答"你讲的是哪个版本"。
> 本页是**基线声明**，不是完整兼容性列表；新增平台时在此登记。

## 一、本库默认基线

| 维度 | 默认基线 | 说明 |
|---|---|---|
| OpenWrt | **23.05** | 主力参考；24.10 作为对照 |
| Linux 内核 | **5.15** | 对应 OpenWrt 23.05 |
| 芯片平台 | **MediaTek MT7981 (Filogic)** | 与 OpenWrt One 一致 |
| 交换机框架 | **DSA** | 新平台默认；swconfig 仅作对比 |
| 无线 | **Wi-Fi 6 (802.11ax)** | mt76/mac80211 |
| 蜂窝 | **LTE Cat.4+ / 5G NSA/SA** | 以模组实际能力为准 |
| 3GPP | **R15 为主，R16/R17 对照** | 5G 特性 |
| 构建 | **OpenWrt Buildroot** | 不用他人魔改树 |

## 二、OpenWrt 版本对照

| OpenWrt | 内核 | 发布特点 | 本库使用 |
|---|---|---|---|
| 21.02 | 5.4 | 旧版稳定，swconfig 仍常见 | 对照 |
| 22.03 | 5.10 | firewall4/nftables 逐步默认 | 对照 |
| 23.05 | 5.15 | 当前主力稳定版 | **默认** |
| 24.10 | 6.6 | 新内核、新驱动 | 对照 |
| main / 25.x | 6.12+ | 开发版，接口可能变 | 仅个案 |

> 本库 `7.平台与集成/1.OpenWrt/1.构建体系/05-镜像原理` 明确基于 `openwrt-25.12`（commit `ecbf832c08`），阅读时注意版本差异。

## 三、芯片与交换机

| 平台 | 架构 | 典型交换机 | 框架 | 备注 |
|---|---|---|---|---|
| MT7620/MT7621 | MIPS | MT7530 | swconfig/DSA | 老设备多 |
| MT7981 | ARM64 | 内置 DSA | DSA | OpenWrt One |
| MT7986 | ARM64 | 内置 DSA | DSA | Wi-Fi 6 |
| IPQ807x | ARM64 | 内置/外置 | DSA | 高通方案 |
| RTL8367 | — | 外置 | swconfig 为主 | 中低端 |

## 四、蜂窝与模组

| 项 | 取值 | 说明 |
|---|---|---|
| 制式 | LTE FDD/TDD、5G NR NSA/SA | 以模组规格书为准 |
| 模组接口 | USB 2.0/3.0、PCIe | 影响吞吐与供电 |
| 驱动 | qmi_wwan、cdc_mbim、option | 与模组协议相关 |
| 管理 | QMI / MBIM / AT | 三选一或共存 |
| 数据通路 | rmnet / IPA / QMAP | 高通平台常见 |
| SIM | 物理 SIM / eSIM | eSIM 需 LPA 支持 |
| 电压/供电 | 3.3V/1.8V、PoE | ODU 重点 |

> **待填**：具体模组型号、固件版本、运营商白名单。见 [open-questions.md](open-questions.md)。

## 五、工具与接口版本

| 工具 | 版本敏感点 | 备注 |
|---|---|---|
| netifd | ubus 接口、proto handler | 笔记需标注 OpenWrt 版本 |
| ubus/uci | CLI 参数、配置格式 | 23.05 与 24.10 有差异 |
| iptables/nftables | 后端切换 | 22.03+ 默认 nftables |
| dnsmasq | 配置项 | 版本差异大 |
| hostapd | 配置项、WPA3 支持 | 需标注版本 |
| QMI | 服务版本（NAS/WDS/UIM） | 模组差异大 |

## 六、标注规则

1. 实现类笔记（L2）必须在 frontmatter 的 `platform` 中列出至少一项。
2. 涉及命令输出的，必须写清"在什么系统/版本上执行"。
3. 无法确认版本的，`confidence: low`，并在正文标注"待核实"。
4. 版本升级导致结论失效时，不删除旧内容，改 `status: deprecated` 并注明替代文档。
